## 3. 摄入方式

采用**热摄入**（不重启服务），逐个调用 `POST /api/documents`：

```json
{ "content": "<文件全文>", "source": "reference/SmartOpsAgent-项目知识/<文件名>", "version": "reference" }
```

设计要点：

- `source` / `version` 与知识服务**启动时扫描语料目录的命名约定完全一致**，避免同内容出现两套来源标识。
- **注意：`/api/documents` 不是幂等接口。** `add_documents` 对每个 chunk 直接 `_chunks.append`，无内容去重，同一文件重复 POST 会重复追加、虚增语料。补录前必须先确认是否已摄入。
