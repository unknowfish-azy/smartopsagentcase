## 六、后续实验优化建议

### P0：准备实验输入

准备少量可追踪的 REAL Agent Trace 或明确标记的 SYNTHETIC Incident，完成 Schema、Quality、Safety、Duplicate、Leakage 和 Human Review，形成非空 Approved Dataset 及 Train/Validation/Test Split。

### P0：完成真实 Baseline

手动配置真实 Ollama 或 OpenAI-compatible Provider；固定 Model、Prompt Version、Knowledge Version、Retriever、Reranker、Tool Policy 和 Evaluator；先运行 Prompt Baseline，再运行 Real Baseline。保存输出、指标分子/分母、延迟、Token 成本和限制条件。

### P1：单变量消融

固定 Dataset、Model、Evaluator、Prompt，每次只改变一个检索变量：`Base → Vector → BM25 → Hybrid → Reranker → Version → Evidence`，之后再运行 Inspector 和 Verification 消融。

### P1：实验报告完整化

每个实验记录 experiment_id、dataset/model/prompt/knowledge version、retriever、reranker、tool policy、metrics 分子/分母、runtime、cost、artifact hash、limitations 和 status。未运行只能写 `NOT RUN`，不能用 `0` 代替。

### P2：训练门禁

Baseline 和三类 Ablation 完成后，再检查训练依赖。只有 Approved Dataset、Leakage、Safety、Split、Model 和依赖全部 READY 才允许 SFT；SFT 评测通过后才允许 Preference Optimization。
