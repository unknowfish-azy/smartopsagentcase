## 0. 为什么是"预测面"，不是"模型演示页"

这类毕设/课程项目的常见界面是一屏图表 + 一堆指标，回答的是"模型跑得怎么样"。
放到智维Agent里，那个问题没有价值 —— 运维要的是**"接下来会不会出事、我该不该现在动手"**。

所以本模块把 MLP+GRU 的预测能力翻译成运维语义：

| 模型语言 | 运维语言 | 界面位置 |
| --- | --- | --- |
| 预测值 / 置信区间 | 预计读数 / 可能范围 | 主图（中位数 + p10–p90 带） |
| 验证集 MAE / RMSE | 这套预测"有多准" | 模型卡的三个数 + 残差条 |
| 特征重要性 / 门控权重 | 它主要在看哪个传感器 | 门控权重条 |
| 阈值告警 | 还有多久越线 | 越界预测卡 + 图上的标记点 |
| 训练/早停/门禁 | 这份预测是不是可信 | 训练与评估条 |
| 传感器采样质量 | 输入本身干不干净 | 数据源表 |

## 1. 用户与场景

| 角色 | 什么时候打开 | 想拿到什么 |
| --- | --- | --- |
| 运维值班 | 告警刚响、或例行巡检时 | 30 秒内会不会越界；要不要现在处理 |
| 处置人 | 收到预测越界提示后 | 依据（哪几个传感器在推）、模型可信度、建议动作 |
| 模型维护 | 每周/每次重训后 | 门禁是否通过、影子模型是否更好、数据源有没有缺采 |

**不在本页做的事**：改阈值、建工单、跑脚本、训练模型。这些分别属于守护 Agent / 告警中心 / 工单中心 / 训练流水线。本页只提供证据和入口。

## 2. 版式

```
┌ 页头：eyebrow · 预测面 · 一句话说明 ──────────────── 数据流 / 模型版本 / DEMO 角标 ┐
├ 工具栏：视野 15/30/60/120s · 传感器 ECT RPM EGT OILP IAT VBAT · 影子模型 · 回放 ┤
├──────────────────────────────────────────┬──────────────────────────────────┤
│ 预测面（主图）                            │ 模型 MLP+GRU（结构/参数/MAE-RMSE-MAPE）│
│  历史实线 + 中位数虚线 + p10–p90 带       │ 门控权重（6 条，主传感器高亮）        │
│  阈值线（预警琥珀 / 越界红）· 现在线       │ 越界预测（还有多久、置信度）           │
│  当前读数角标 · 悬停十字线 + 数值提示      │                                      │
│  x 轴 −120s → +视野                       │                                      │
├ 残差条 + 窗口 MAE ────────────────────────┤                                      │
├──────────────────────────────────────────┴──────────────────────────────────┤
│ 训练与评估（loss 曲线 · 门禁 · 最佳 epoch · 下次重训） │ 数据源（采样/缺失/延迟）   │
└──────────────────────────────────────────────────────────────────────────────┘
```

- 桌面：主图占 `1fr`，右侧 344px 三卡竖排；底部一条两栏（训练 1.35fr / 数据源 1fr）。
- `≤1180`：右侧三卡变两列，底部两栏叠为一行。
- `≤760`：全部单列，主图 340px 高，构成谱/工具栏换行。
- 主图**不放进卡片网格里当普通卡片**：它是整页的"主证据面"，因此占据左侧全部宽度，高度 460（窄屏 340）。

## 3. 主图规格

| 元素 | 画法 | 说明 |
| --- | --- | --- |
| 历史 | 实线 1.6px，`--ds-chart-1`（#2496ED），下方 8% 填充 | 最近 120s，2s 一点 |
| 预测中位数 | 虚线 6/4，`--ds-chart-2`（#7AD7F5） | 从"现在"开始到视野末端 |
| 不确定带 | p10–p90 填充 12% + 边框 28% | 宽度随 √h 增长（演示数据同口径） |
| 阈值 | 预警琥珀 `#D29922`、越界红 `#F85149`，4/4 虚线 + 右端标签 | 只画视野内可见的 |
| 现在线 | 竖虚线 + 3px 圆点 + 读数角标（`93.1 °C`） | 历史与预测的分界 |
| 越界标记 | 圆点 4.5px + 8px 外环，颜色随级别 | 点击列表项可定位 |
| 十字线 | 竖虚线 + 圆点 + 浮层（值 / 时间偏移 / p10–p90） | 悬停；点击固定，再点取消 |
| 轴 | 4–7 条水平网格，y 轴取整刻度（1/2/2.5/5/10 × 10ⁿ） | 时间轴 30s 一格，"现在"高亮 |

**y 轴取整规则**：`step = niceStep((max−min)/4)`，范围向 step 取整；标注用 `toLocaleString` 保留传感器位数（温度 1 位、压力 2 位、转速 0 位）。这样读数不会出现 `92.9` 这类"假精度"。

**阈值出视野**：坐标轴只按数据与预测区间取范围；阈值若在范围之外，退化为右上 / 右下的边缘标记（预警 96.0 ↑），不再为了画线而把坐标轴拉到 105。

**残差条**：最近 120s 的逐步误差（|实测 − 6 秒前外推|），柱高按传感器幅度归一化；超过 35% 幅度转琥珀。右侧给"窗口 MAE + 演示值"。

## 4. 侧栏三卡

### 4.1 模型卡
- 结构：`输入 12×6 → GRU 64 → GRU 32 → MLP 16→1`，横向块 + 箭头，`overflow:auto`。
- 指标：MAE / RMSE / MAPE 三格，单位随主传感器切换。
- 页脚：参数量、训练时间、epoch 数。
- `DEMO` 角标：无真实模型时永远显示。

### 4.2 门控权重
- 6 条横向条，值域 0–1，主传感器高亮为青色。
- 标注 `STRUCTURAL`：这是"模型在看什么"，不是"贡献度百分比"，不写 %。

### 4.3 越界预测
- 每条：传感器（中文 + EN）· 还有多久（`+20s`）· 阈值 · 置信度。
- 顺序按时间；最多 4 条；点击可把该传感器设为主序列。
- 主传感器视野内无越界时，显示一句解释 + 建议拉长视野，而不是空白。
- 置信度 = 演示公式 `0.9 − h/(4×视野)`，落在 0.5–0.9；真实实现应由后端给。

## 5. 训练与评估条

- 左：一句话说明"早停只看验证集"。
- 中：train / val 两条 loss 曲线（0–46 epoch），val 虚线。
- 右：门禁状态（通过 / 未通过）、最佳 epoch、下次重训倒计时。
- 门禁颜色：通过用 `--ok`，未通过用 `--warn`；**不用红色**，因为"未通过"不等于故障。

## 6. 交互

| 交互 | 行为 | 约束 |
| --- | --- | --- |
| 视野 15/30/60/120s | 预测段重算，带变宽，越界列表重排 | 过渡 ≤ 400ms；不做轴翻转 |
| 传感器切换 | 主图换序列，阈值换线，门控高亮 | 保留视野与游标 |
| 影子模型 | 叠加 v3.3 的虚线（不改变主序列与带） | 只读对比，不写任何状态 |
| 回放 / 暂停 | 每秒 3 个"虚拟秒"推进；暂停后 rAF 停止 | `prefers-reduced-motion` 默认暂停 |
| 悬停 / 点击 | 十字线 + 浮层；点击固定 | 键盘 ←/→ 移动游标，空格播放/暂停 |
| 越界项点击 | 切到该传感器并定位 | 不触发任何写操作 |

**键盘可达**：工具栏按钮全部原生 `<button>`；`aria-pressed` 表示选中；图表用 `role="img"` + 文字替代描述（"历史与预测区间示意图"），具体数值在浮层与列表中可读。

## 7. 数据契约（建议）

```http
GET /api/sentinel/forecast?metric=ect&horizon=30
200 {
  "generatedAt": "2026-11-19T15:20:31Z",
  "model": { "version": "v3.2", "arch": "MLP+GRU", "params": 28417,
             "metrics": { "mae": 1.84, "rmse": 2.61, "mape": 2.3 },
             "trainedAt": "2026-11-18T21:40:00Z", "epochs": 42, "gate": "PASS" },
  "points": [ { "t": 0, "median": 93.1, "p10": 92.4, "p90": 93.8 } ],
  "crossings": [ { "kind": "warn", "h": 20, "value": 96.0, "confidence": 0.73 } ]
}

GET /api/sentinel/series?metric=ect&window=120
200 { "points": [ { "t": -120, "v": 84.2 } ] }

GET /api/sentinel/forecast/models
200 { "models": [ { "version": "v3.2", "gate": "PASS" }, { "version": "v3.3", "gate": "PENDING" } ] }
```

- 单位随 metric 返回，前端不做换算。
- 缺字段即视为不可用，不补默认值。
- 三态：`loading`（骨架，不闪烁）/ `live`（LIVE 角标）/ `demo`（DEMO 角标，虚构数据）/ `offline`（—，说明为什么）。

**演示数据**：前端用确定性合成序列（正弦 + 慢漂移 + 平滑噪声），保证同一时刻刷新画面一致；页脚与角标双重声明"虚构示例"。

## 8. 动效

| 项 | 值 |
| --- | --- |
| 图线重绘 | 数据/交互变化时重绘；回放时 30fps 节流 |
| 视野切换 | 带与中位数 300–400ms 重新计算（直接重绘，不做补间动画） |
| 读数角标 | 不滚动数字，直接显示当前值（避免 count-up 制造假实时感） |
| 悬停浮层 | 120ms 淡入 |
| 回放 | 单一 rAF，暂停即停；reduced-motion 下不自动播放 |

**禁止**：粒子、WebGL、图表扫光、红绿涨跌、数字翻滚、背景极光叠加。本页已有"动"的信息（游标、回放），不需要氛围层。

## 9. 可访问性

- 图表 `role="img"` + `aria-label`；所有数值在侧栏列表与浮层里文字可读。
- 工具栏 `role="toolbar"`，视野用 `aria-pressed`，传感器 chips 同。
- 键盘：Tab 顺序 = 视野 → 传感器 → 对比 → 回放 → 越界列表；`←/→` 移动游标、空格回放。
- 对比度：正文 `#E8F2F7` / `#92A6B5` 在 `#0E1116` / `#151A21` 上均 ≥ 4.5:1；琥珀与红只用于阈值与越界语义。
- 触控目标 ≥ 30px 高，窄屏工具栏换行不压缩点击区。

## 10. 与既有页面的边界

| 页面 | 关系 |
| --- | --- |
| 哨兵监控台 `/sentinel` | 它管"现在有没有告警"；预测面管"接下来会不会" |
| 守护 Agent `/sentinel/guardian` | 它产出**阈值建议**（人工确认后写回）；预测面只读预测，不改阈值 |
| 告警中心 `/sentinel/alerts` | 预测越界不是告警；需要人确认后才可能变成告警 |
| 模型强度 `/model-strength` | 它看 LLM 调用的可用性；预测面看数值模型的误差与门禁 |
| 执行轨迹 `/agent/trace` | L1 的动效语义已落在这里，预测面**不重复挂**同类动效 |

## 11. 设计稿怎么用

`index.html` 是自包含的可交互设计稿（无依赖、离线可开）：

- 直接双击打开即可；或用 `node` 起任意静态服务器。
- 可切换视野、传感器、影子模型、暂停/回放，悬停看十字线与浮层。
- 全部数据为**确定性合成序列**，页面上有 `DEMO` 角标与页脚声明。
- TRAE 实现时以本稿为视觉基线，以 §7 的接口形状为数据基线；**不要**把稿里的合成数据当成后端返回值。
