# 纠察星云投影（Nebula Projection）设计文档 v1.0

> 2026-11-15 立项。灵感源：小红书「Claude Code 套利机器人」视频中的**球状粒子星云**（数万粒子绕核旋转、多彩轨迹）——只借观感，粒子全部绑真实纠察事件。
> 编号：工作包 **T32**（与工坊包 T28–T31 并列）；待裁决 D13–D14。
> 上位先例：洞察台三视图（`903756b`）、红框三页改造（`8c4d8d1`）。

---

## 1. 一句话定位

洞察台新增**第 4 投影「星云 NEBULA」**：每颗粒子 = 一条真实纠察事件，球面环带按等级分布、经度按时间展开、慢速自转，点击粒子打开与点/柱/条视图**同一个**证据抽屉——切视图不换轴，星云只是同一批事件的第 4 种看法。

## 2. 视觉设计

```
        ╭───────╮            4 条纬度环带 = 四等级
       / CRITICAL ╲             （PASS 赤道 → CRITICAL 北极圈，
      |  ● ● HIGH  |               与平面时间轴的 Y 轨道同构）
      | ● PASS ● ● | ●          经度 0°–360° = 时间窗（24h/7d）
       \ WARNING  /             粒子亮度 = 距今越近越亮
        ╰───────╯               呼吸微光 + 慢速自转（≈28s/圈，视觉调校自 40s）
```

- **渲染**：Canvas 2D + 手写 3D 投影（旋转矩阵 + 透视除法），**不引 three.js**（bundle 红线：登录首屏刚清完 71KB 误载，不再引 600KB+ 的 3D 库）。
- **配色**：等级色沿用纠察中心四色令牌；维度色沿用 `dimensions.js` 8 色带（hover 时粒子按维度重着色，形成"色环扫描"效果——视频里多彩轨迹的低成本等价物）。
- **背景**：`--ds-surface`，星云核（圆心）画一个极淡 hairline 圆环 + 等级刻度，不画科幻渐变。
- **转场**：从点/柱/条切到星云时，粒子从对应平面位置**汇聚成球**（600ms transform），强化"同一批事件换投影"的叙事——这是比静态球更打动评委的一笔。

## 3. 数据与交互（零新契约）

- 数据源：复用 `/api/inspector/events`（`id/createdAt/severity/taskId/category/target/traceId/reason/recommendation`），与三视图完全同源。
- 纬度 = severity（4 环带）；经度 = createdAt 在当前时间窗内的比例；粒子数 = 窗口内事件数（预算见 §4）。
- **hover**：粒子放大 + tooltip（taskId/等级/维度/时间），其余粒子降透明度；
- **click**：开既有 `DeskDrawer` 证据抽屉（选中态同步回点/柱/条视图）；
- **空态**：沿用三视图现成空/错态；**DEMO 态**：沿用现有双重虚构标注，星云核显示 `DEMO` 水印。

## 4. 性能预算与降级（四重门禁复用）

| 层 | 策略 |
|---|---|
| 粒子上限 | 1000（超出按时间窗均匀抽样并在脚注标注"已抽样 n/总数"） |
| reduced-motion | 静态单帧：不自转、不呼吸，hover/click 交互保留 |
| 掉帧 | 降采样至 500 → 250；再降关闭转场汇聚动画 |
| 窄屏 <768px | 星云 tab 隐藏，回落三视图（列表已够用） |

渲染纪律：30fps 经 `motionScheduler` 调度；仅 `canvas` 绘制与 `transform/opacity`，禁 blur/阴影堆叠。

## 5. 验收门禁

1. typecheck 0 / lint 0 error / 双端构建 / 全量单测不回退；
2. 浏览器实测：真实数据 ≥3 等级粒子可见、hover tooltip、点击开抽屉且选中态联动、转场汇聚动画、DEMO 态水印、0 报错；
3. a11y：星云容器 `role="img"` + aria-label（粒子总数/等级分布摘要）；键盘提供"下一事件"遍历（Tab 序列）；
4. 无事件静默：空窗口显示空态而非空转球；
5. 粒子上限抽样时脚注如实标注；
6. `git diff` 不含 DeskAxis/DeskDrawer/DeskSelection/DeskTotals 的行为改动（只允许 DeskProjections 加分支）。
