## 1. 用户诉求与边界

- 用户原话：「我想把上面的特效设计成我的项目里，**和上面功能无关**」。
- 即：取视频中**等距工坊的视觉语言**（工位、亮灯、缆线脉冲、墙屏、机柜指示灯、机器人小人），作为本项目 **Agent 构成场的第二视图层**。
- 明确不借（红线）：
  1. 任何金额/收益/余额曲线（D3 裁决「不伪造数据」）；
  2. 霓虹粉低对比配色（T11 a11y 对比度门禁）；
  3. 位图像素 sprite（破坏令牌化双主题体系）；
  4. 假繁忙——所有亮灯/脉冲必须绑真实运行时事件。

## 2. 落点与接入方式

- **宿主**：`frontend/src/views/agent/AgentModuleView.vue`（FABLE 5.2 构成变换页）。
- **接入方式**（复用照片墙先例）：stage-head 增加二选一视图 pill——`构成 / 工坊`。**默认保持「构成」**（省赛材料、演示分镜均已按 Fable 口径录制，零破坏）；「工坊」为国赛新增演示层。
- 既有 Fable 全部组件（FableComposition/FableGaze/FatBlob/五面板）零改动，切换仅替换 `fable-stage` 内的渲染分支。

## 3. 画面结构（工坊全景）

等距 2.5D 房间（SVG 绘制，非 3D 引擎），暗色 tool surface 为底：

```
┌────────────────────────────────────────────────┐
│  墙屏(实时闭环统计 sparkline)      服务器机柜×1   │
│                                                │
│   [检索工位] [策略工位] [审批工位]   🪴 绿植(静态) │
│        \        |        /                     │
│   ──── 中央循环轨道: 感知→规划→执行→核查 ────     │
│        /        |        \                     │
│   [执行工位] [核查工位] [审计工位]   时钟/状态牌   │
└────────────────────────────────────────────────┘
```

- **6 张工具工位** = 既有 `TOOLS` 六件（混合检索/风险策略/人工审批/安全执行/结果核查/审计留痕），每工位一张等距桌台 + 一台终端 + 一个几何小人。
- **中央循环轨道** = `LOOP_STEPS` 四站（感知→规划→执行→核查），传送带式环形连线，事件沿轨道流动。
- **墙屏** = 真实 `getDecisionLoopStats` 的 sparkline（复用 OpsChart 或内联 SVG 折线）。
- **服务器机柜** = 指示灯随 SSE 心跳闪烁（有心跳才闪，断连常灭）。
- **装饰**（绿植、时钟、地垫）= 纯静态，不动画，不绑数据。

## 4. 特效清单（借什么、怎么动）

| # | 特效 | 视频原型 | 本项目实现 | 数据源 |
|---|------|---------|-----------|--------|
| E1 | 工位亮灯 | 机器人干活灯亮 | 桌面终端屏点亮 + 小人起手动画（600–900ms） | `getDecisionLoops` 最近闭环的当前 step 命中工具 |
| E2 | 缆线脉冲 | 楼层间能量流 | 等距连线上的光点匀速滑过（一次事件一颗，不常驻） | 闭环 step 推进（感知→规划→…） |
| E3 | 轨道流转 | 传送带 | 四站环形轨道上事件徽章逐站移动 | 同 E1 同源，禁止独立随机 |
| E4 | 墙屏 sparkline | 行情屏 | 近 N 轮闭环耗时的真实折线 | `getDecisionLoopStats` |
| E5 | 机柜心跳灯 | 机房灯闪 | 3 颗 LED 随 SSE/轮询心跳明灭 | 数据拉取成功即一次心跳 |
| E6 | 小人注视 | 机器人转头 | 空闲小人头朝向当前活跃工位 | 同 E1 |
| E7 | 空闲呼吸 | 待机微动 | 全屋 7.4s 呼吸（沿用 Fable 呼吸周期）纯 transform | 无数据，装饰级 |

**动效纪律**：全部走 `motionScheduler.subscribe` 统一调度（30fps 预算内）；`prefers-reduced-motion` → **静态单帧**（亮灯状态保留、动画归零，与 Fable 同规）；掉帧降级沿用三档视觉；E1–E6 在无真实事件时**全部静默**，绝不做假繁忙。

## 5. 视觉与令牌

- 形象抽象度：**几何小人**（圆头 + 梯形身，SVG rect/circle/path 拼装），不像素画、不拟人化到脸。等距投影用 2:1 isometric（30° 轴测），纯 `transform` 摆位。
- 色彩：底面 `--ds-surface`/`--ds-surface-raised` 双档 + hairline 描边；工位色沿用 Fable 六色（sage/clay/butter/apricot/gaze/plum）作为**点缀色**（≤15% 面积），亮灯高亮用各工位 tone 的 600 阶。**禁**霓虹粉/荧光绿大面积铺陈。
- 双主题：几何体用 CSS 变量取色，浅色主题同构自动成立（Fable 已验证此路径）。
- 对比度：所有文字标签（工位名/状态牌）走既有正文令牌，进入 T11 对比度矩阵复测。

## 6. 数据契约（零后端新增）

- 复用 `GET /api/agent/decision-loops`（`getDecisionLoops`）与 `getDecisionLoopStats`：工坊是**既有闭环数据的另一种投影**——与洞察台「三视图联动」同哲学：切视图不换轴。
- DEMO 态（后端不可用）：整屋呈「休眠」灰调 + 页脚标注 `REHEARSAL · 演练构成`（沿用证据规则：只呈现运行时事实或标注 SAMPLE/REHEARSAL）。

## 7. 降级与门禁（12 条）

1. reduced-motion → 静态单帧，0 动画；
2. 掉帧检测触发 → 关闭 E2/E7 脉冲类，保留状态亮灯；
3. 视觉三档（rich/balanced/quiet）联动既有 `visualMode`；
4. 窄屏 <768px → 工坊退化为「工位状态列表」（名字 + 灯态 + 最近事件时间）；
5. 亮灯必须可溯源：hover 工位出 tooltip（闭环 id / step / 耗时 / 时间），点击跳闭环记录面板；
6. 无事件静默（禁假繁忙）；
7. DEMO/演练态显式标注；
8. 双主题对比度 0 严重（axe 复测）；
9. 键盘可达：Tab 遍历工位（role=button + aria-label 含状态）；
10. 切视图不换数据轴：构成/工坊共享同一 `liveField`/loops 数据源；
11. 动画全走 transform/opacity（无 blur/无 layout 抖动）；
12. 构建门禁：typecheck 0 / lint 0 error / 双端构建 / 全量单测不回退 / 浏览器实测 0 报错。
