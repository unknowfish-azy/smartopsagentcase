# AI 对话与历史会话

首页保留轮播和功能入口，完整聊天位于 `/chat`。桌宠与 AI 对话页共享当前选中的会话。

## 使用方式

- 在会话侧栏新建、搜索、切换会话。标题默认取首条问题；更多菜单支持重命名和删除，删除需要确认。
- 按今天、昨天、最近 7 天和更早分组。搜索同时匹配标题与消息正文。
- 窄屏点击标题旁的历史按钮打开抽屉；选择会话后自动收起。
- 切换会话不会把正在生成的回复写到另一段对话；删除会话后，迟到的回复不会恢复它。

## 保存范围

- 记录按登录用户名保存在当前浏览器的 localStorage，键前缀为 `smartops_chat_history:v1:`，刷新后恢复。
- 不写入服务器数据库，不支持跨设备同步。清理网站数据会删除历史；同一浏览器的账号区分不等同于加密或服务器访问控制。不要在会话中输入密码、密钥等敏感信息。
- 浏览器禁止存储或空间不足时，界面提示保存失败，本次消息仍可继续显示。
- 刷新时尚未完成的回复会标记为已中断，可以重新发送问题。
- 继续对话时向现有模型调用接口附带当前会话最近 20 条有效消息，并将历史上下文限制在约 24000 字符内；完整记录仍保留在历史列表中。

## 验证

在 `frontend` 目录执行：

```powershell
node --test test/ai-chat.test.mjs test/chat-history.test.mjs test/spider-chat-integration.test.mjs
node --test test/chat-history.browser.mjs test/ops-spider-interaction.browser.mjs
npm.cmd run build
```

浏览器测试需要本地 Vite 服务在 5173 端口运行，并使用本机 Edge。聊天请求由测试拦截，不调用真实模型或产生模型费用。
