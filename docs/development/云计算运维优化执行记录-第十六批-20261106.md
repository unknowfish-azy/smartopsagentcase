## 二、OPS-06 结论：部分通过（保持未勾）

### 变化：两层不再是无证据的固定 UNVERIFIED

[NetworkPathService.java](file:///d:/SmartOpsAgent/backend/src/main/java/com/smartops/diagnostics/network/NetworkPathService.java#L477-L578) 新增主机侧只读采集：

| 层 | 命令 | 判定 |
|---|---|---|
| SECURITY_GROUP | `iptables -S`；无命令时回退 `nft list ruleset` | 采集到规则 → `UNVERIFIED` + `HOST_FIREWALL` 证据 + `CLOUD_SECURITY_GROUP` 未接入；权限/forbidden → `NO_PERMISSION`；两种工具都没有 → `UNVERIFIED` 并写明原因 |
| ROUTE | `ip route get <host>` | 无路由（RTNETLINK）→ `FAILED` 带真实报错；权限 → `NO_PERMISSION`；可达 → `UNVERIFIED` + `HOST_ROUTE` 证据（dev/via/src）+ `CLOUD_VPC_ROUTE` 未接入；无 `ip` 命令 → `UNVERIFIED` |

两层仍保持 `UNVERIFIED` 是刻意的：主机防火墙/路由表不等于云安全组与 VPC 路由表，不能用主机侧证据宣布链路通过。
