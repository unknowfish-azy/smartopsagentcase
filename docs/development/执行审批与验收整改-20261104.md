## 3. 接入边界

宿主必须先认证 reviewer 身份，再调用创建/批准/拒绝；实例应只由可信进程持有。Python 模块自身没有 reviewer 身份认证服务，字符串 reviewer 不等于完成身份验证。审批状态仅保存在当前 ApprovalManager 进程内，重启全部失效，多 worker 不共享。旧 create_request/approve/reject 接口仍可记录信息，缺少绑定指纹的旧记录不放行执行。

本批未新增公开审批 HTTP 接口、数据库审批表、Java 团队/哨兵审批桥接或持久化恢复。现有调用者需要显式传入同一管理器；旧调用未配置审批时高风险动作会被拒绝，这是本批有意收紧的契约。

以下本地预检示例只验证绑定批准，不运行工具，可在项目根目录用 Python 执行：

```python
from types import SimpleNamespace
from agent.executor.models import ExecutionContext
from agent.planner.steps import PlanStep
from agent.policies.policy_engine import PolicyEngine
from agent.safety.approval import ApprovalManager

manager = ApprovalManager()
context = ExecutionContext("demo-request", "demo-user", environment="demo")
step = PlanStep(1, "重启 mysql", "server.restart", {"service": "mysql"}, requires_approval=True)
tool = SimpleNamespace(name="server.restart", risk_level="HIGH", requires_approval=True)
policy = PolicyEngine(approval_manager=manager)
assert not policy.check(tool, context, step).allowed
request = manager.create_for_step(context, step)
# 此例中本地宿主充当已认证 reviewer；生产宿主须先验证真实身份。
manager.approve(request.approval_id, "local-host-reviewer")
context.approval_id = request.approval_id
assert policy.check(tool, context, step).allowed
step.arguments["service"] = "redis"
assert not policy.check(tool, context, step).allowed
print("bound approval preflight verified; no tool executed")
```
