## 2. OPS-12 实现与验收口径

### 2.1 计划分析（[TerraformPlanAnalyzer.java](file:///d:/SmartOpsAgent/backend/src/main/java/com/smartops/iac/TerraformPlanAnalyzer.java)）

`POST /api/iac/plans/analyze`，输入 `terraform show -json` 的计划 JSON：

- 只保留 `address / type / name / module_address / action / destructive`，**不保存 before/after 属性值**，避免密码、密钥随计划落库；
- 动作归类 `create / update / delete / replace / read / no-op`，出现 `delete` 即 `destroyDetected=true`，`delete+create` 记 `replace`；
- 计划摘要 = `terraform_version|lineage|serial|address=action;...` 的 SHA-256：同一结构稳定，属性值变化不改变摘要；
- 非法输入区分 `IAC_PLAN_EMPTY`、`IAC_PLAN_MALFORMED`、`IAC_PLAN_NOT_TERRAFORM`（缺少 `resource_changes` 不是"无变更"）、`IAC_PLAN_FORMAT_UNSUPPORTED`。

### 2.2 治理链路（[IacService.java](file:///d:/SmartOpsAgent/backend/src/main/java/com/smartops/iac/IacService.java)）

| 步骤 | 接口 | 证据与约束 |
| --- | --- | --- |
| 保存计划 | `POST /api/iac/plans` | 同 workspace+摘要幂等返回同一条，避免多个"已批准"副本 |
| 审批 | `POST /api/iac/plans/{id}/approve` | 销毁型计划必须 `confirmDestroy=true`；生成审批码并绑定批准人/时间 |
| 下发 | `POST /api/iac/plans/{id}/dispatch` | 审批码校验；同 workspace 已存在 `DISPATCHED` 返回 `IAC_STATE_LOCKED`；出现更新计划返回 `IAC_PLAN_STALE`；只记 `SENT` |
| 执行确认 | `POST /api/iac/applies/{id}/complete` | 必须引用本人 `operation_run_record.trace_id`；Run 为 `SUCCEEDED` 且退出码 0 才 `APPLIED`；矛盾/失败/不确定如实记录 |
| 变更后验证 | `POST /api/iac/applies/{id}/verify` | 至少一条检查，全部通过才 `VERIFIED`；否则 `VERIFICATION_FAILED`，不写 `verified_at` |
| 发布历史 | `GET /api/iac/releases?workspace=` | 记录 commit、镜像 digest、方向（DEPLOY/ROLLBACK）、状态、前后发布 |
| 漂移 | `GET /api/iac/drift?workspace=` | 期望=最新计划，实际=最后发布；`IN_SYNC / DRIFT / NO_RELEASE / NO_PLAN / NO_HISTORY` |
| 受控回滚 | 计划请求带 `rollbackOfReleaseId` | 目标发布必须同 workspace，且 commit/镜像 digest 与目标发布一致，否则 `IAC_ROLLBACK_TARGET_MISMATCH`；成功回滚生成 `ROLLBACK` 发布并指向上一发布 |

## 3. OPS-13 实现与验收口径

### 3.1 恢复集合与清单（[BackupService.java](file:///d:/SmartOpsAgent/backend/src/main/java/com/smartops/backup/BackupService.java)）

- 五类组件：`DATABASE`、`ATTACHMENTS`、`KNOWLEDGE_MANIFEST`、`AUDIT`、`KEYS`；集合缺任一类，`status` 与 `SetView.complete=false` 如实标 `INCOMPLETE`；
- 清单 `smartops-backup/v1`：只收 `artifactId/component/sourceUri/sha256/bytes/itemCount/capturedAt`，校验 64 位 hash、组件属于集合、ID 不重复；
- 保留期 `retentionUntil = capturedAt + retentionDays`，过期制品在状态中单列；
- 校验接口接收恢复副本实际的 sha256 与条目数：一致 `VERIFIED` 并写 `verified_at`，不一致 `MISMATCH` 且不写验证时间；
- 异机副本位置与验证时间分开：只复制未校验时 `offsite_verified_at` 为空，并出现在 `unoffsiteArtifacts`。

### 3.2 隔离恢复演练与 RPO/RTO

`POST /api/backups/sets/{id}/drills`，只接受 `ISOLATED_RESTORE`：

- 基线 = 集合内制品最晚 `capturedAt`；`RPO = 演练开始 - 基线`，`RTO = 演练结束 - 演练开始`，由服务端计算，不接受调用方自报；
- 结果 `VERIFIED` 需同时满足：恢复数量 = 期望数量且 >0、hash 校验通过、引用关系 `PASS`、关键查询 `PASS`、且集合每个组件都有制品；
- 任一不满足记 `FAILED`；制品缺失或集合不完整记 `UNVERIFIED`，详情列出缺失组件。

### 3.3 备份脚本

- [backup.sh](file:///d:/SmartOpsAgent/deploy/server/backup.sh)：`mysqldump --single-transaction` 导出数据库；tar 打包附件/审计/密钥；复制知识 manifest；生成清单；可选 `OFFSITE_TARGET` rsync 异机复制；按 `RETENTION_DAYS` 清理；密码走 `MYSQL_PWD` 不进进程参数，`umask 077`。
- [build_manifest.py](file:///d:/SmartOpsAgent/scripts/backup/build_manifest.py)：标准库实现；文件取 sha256/字节/1 条目；目录按相对路径排序后对 `relpath:sha256` 聚合取 sha256，恢复副本可复算；缺五类组件默认退出码 2，`--allow-partial` 才允许部分备份。

### 3.4 目录备份、持久卷与可恢复备份的边界

| 类型 | 覆盖范围 | 不能替代什么 |
| --- | --- | --- |
| 目录备份（本批 `backup.sh`） | 附件、审计导出、密钥、知识 manifest 文件；数据库走逻辑导出 | 不保证运行中写入的崩溃一致性；不含容器/PV 内未挂载到这些目录的数据 |
| 持久卷快照（存储/CSI 层） | PVC 整体块级/文件系统快照，恢复快、适合大附件 | 快照成功 ≠ 数据库一致；需应用静默或事务日志配合；跨集群恢复需存储侧能力 |
| 可恢复备份（本批验收对象） | 逻辑导出 + 各组件制品 + sha256 清单 + 异机副本 + 隔离恢复演练 | 只有完成演练并核对数量/hash/引用/关键查询，才记为 `VERIFIED`；复制成功、脚本退出 0 都不算 |

## 5. 已知限制

1. **Terraform 真实执行未在测试中跑**：集成测试通过插入的 `operation_run_record` 验证执行证据链路；真实 `terraform apply` 需在部署环境由工具链执行后回填 trace_id。
2. **备份脚本未在本机执行**：本机无 MySQL/mysqldump 与 Linux 环境，脚本只做了人工审阅；部署后需先跑一次 `backup.sh` 并用恢复演练核对。
3. **异机副本未端到端验证**：`rsync` 路径需由运维环境提供，复制后仍需演练验证，系统不把复制成功记为可恢复。
4. **演练检查为操作者提供的事实**：`restoredCount`、`hashVerified`、引用与关键查询结果由演练执行者提供，后端负责一致性约束与时间计算，不能替代真实演练。
5. **持久卷快照不在本批范围**：需存储侧（CSI/云盘快照）配合，已在 3.4 说明边界。

## 6. 回滚方式

- `git revert <sha>` 回退代码与脚本；两个迁移只新增表与可空列，回滚代码后遗留表不影响运行。
- 回滚后 `/api/iac`、`/api/backups` 接口消失；已登记的计划/发布/制品记录仍在库中，需按需清理或保留作为审计证据。
- 回滚工具目录会移除 3 个 terraform 只读工具，不影响既有 `terraform-environment`。
