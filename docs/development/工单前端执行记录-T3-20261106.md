## 2. 关键口径

- **三态诚实**：`ready / unauthorized / unavailable` 与哨兵模块一致；未登录提示先登录、接口缺失明说"后端未接入"，**不填充假数据**（测试断言覆盖）。
- **状态机以后端为准**：前端 `allowedTransitions` 只做提前禁用；未知状态返回空列表——一切按钮禁用（fail-closed），测试覆盖 `MITIGATING→ACK` 非法转移与未知状态。
- **关闭不缺项**：三字段任一为空白即禁用提交，后端 `@NotBlank` 兜底；提示语写明"后端强制校验"。
- **SLA 不撒谎**：`slaRemainingMinutes` 纯函数、时间由调用方注入；CLOSED/RESOLVED 显示"已结束"，无截止显示"—"，负数显示"超时 N 分钟"。
- **身份不伪造**：所有写操作不携带 actorId，由后端从会话上下文取。
