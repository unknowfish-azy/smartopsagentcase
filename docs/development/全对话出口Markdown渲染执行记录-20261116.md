# 全对话出口 Markdown 渲染执行记录（2026-11-16）

## 背景
用户截图反馈：首页「智能进化 · 小鱼」卡片里，AI 回复的 `**加粗**`、` ```bash ` 围栏代码块以字面符号原样显示，未渲染成 Markdown。

## 排查结论
项目已有 XSS 安全的 Markdown 渲染器 `frontend/src/components/ai/markdown.js`（先转义再转换，链接仅放行 http/https），主聊天面板 `AiChatPanel.vue` 已接入；但有两处 AI 对话出口漏接：

1. `components/dashboard/XiaoyuDashboardCard.vue`（截图所在处）—— `{{ msg.content }}` 纯文本；
2. `components/common/OpsSpiderPet.vue`（桌宠对话）—— 同样纯文本。

**额外发现两个真实缺陷**：

- **样式失效**：`.ai-chat-markdown p` 等后代选择器写在 `<style scoped>` 里，而 `v-html` 生成的元素不带 `data-v-xxx`，永远匹配不到 —— 原 `AiChatPanel` 的 Markdown 样式其实一直未生效。
- **渲染器 bug**：`inlineChildren()` 收集段落时没有在块级起始行停下，导致紧跟段落/列表的 ` ``` ` 围栏被吸进 `<p>`；行内代码正则 `/`([^`]+)`/` 又把连续三个反引号错误配对，整段代码块塌成普通文本——这正是截图里 ` ``bash ` 畸形显示的根因。

## 改动
| 文件 | 变更 |
|---|---|
| `components/ai/markdown.css`（新增） | 全局 Markdown 样式（保证 `v-html` 后代可命中），三处出口共用；含紧凑容器字号覆盖与 `pre-wrap` 特异性覆盖 |
| `components/ai/AiChatPanel.vue` | 删除失效的 scoped 样式，改 import 全局样式 |
| `components/ai/markdown.js` | 新增 `isBlockStart()`；`inlineChildren()` 遇围栏/标题/引用/列表立即停止，交还主循环按块解析 |
| `components/dashboard/XiaoyuDashboardCard.vue` | 助手完成态消息走 `renderMarkdown` + `v-html`；用户消息/错误/流式进行中仍为纯文本 |
| `components/common/OpsSpiderPet.vue` | 同上；`:deep()` 覆盖容器的 `pre-wrap` |

## 口径
- 流式输出期间保持逐字纯文本 + 光标，`done` 后一次性切 Markdown，与既有主面板策略一致；
- 用户消息、错误消息不做 Markdown 渲染；
- 所有 HTML 先转义，`<service>` 等尖括号内容在代码块里被转义为实体，无注入面。
