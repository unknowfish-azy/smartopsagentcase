- 迁移 `V20261105.7__alert_lifecycle.sql`、`V20261105.10__alert_silence_governance.sql`。
- 去重按 `group_key` 聚合，恢复自动关联关闭；[AlertLifecycleService.java](file:///d:/SmartOpsAgent/backend/src/main/java/com/smartops/sentinel/AlertLifecycleService.java)。
- 静默治理：
  - GLOBAL 窗口 >24h 且申请人非管理员 → `PENDING_APPROVAL`，**审批前不抑制任何告警**（`AlertSilence.isActive` 只认 `status='ACTIVE'`）；管理员 `POST /api/alerts/silences/{id}/approve` 后生效并记录审批人。
  - 外部平台（Alertmanager）同步：[AlertmanagerSilenceClient.java](file:///d:/SmartOpsAgent/backend/src/main/java/com/smartops/sentinel/AlertmanagerSilenceClient.java)；未配置记 `NOT_CONFIGURED`，失败记 `FAILED` + 原因，**不显示成功**。
  - 撤销先撤外部：外部撤销失败抛 502 且本地记录保留，避免"接口说撤销了、平台还在静默"。
  - TTL 上限 7 天；到期后 `active=false` 但记录保留可核验。
- 工具目录 `alerts-suppress` 由"不可用占位"改为真实入口说明（mutating，走审批链）。

### 2.6 OPS-08 主机/中间件/JVM 诊断
- [diagnostics/host](file:///d:/SmartOpsAgent/backend/src/main/java/com/smartops/diagnostics/host)、`POST /api/operations/host/diagnose`。
- 11 项检查全部只读；预算 14 条命令 / 单命令 10s / 整单 60s，超预算 `truncated`；采样窗口 `sampleSeconds`（1..5）。
- 三态诚实：无 nginx/java/redis → `NOT_APPLICABLE`；无 iostat/jcmd/timedatectl → `UNVERIFIED`；stderr 含 forbidden → `UNVERIFIED` 且注明"权限不足，未核验"；证据单行 ≤300 字，不整段读日志、不输出完整 nginx 配置/线程栈。
