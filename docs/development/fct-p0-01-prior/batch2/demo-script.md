# 智维Agent 竞赛演示视频脚本

> 时长目标：**7 分 00 秒**（要求 5–8 分钟）；分辨率 **1920×1080**；MP4（H.264）
> 演示主线：**一个真实故障从"被描述"到"被可信地处理完"**，而不是罗列页面。

## 1. 录制规格

| 项 | 要求 |
| --- | --- |
| 画布 | 1920×1080，30 fps，浏览器缩放 100% |
| 音频 | 普通话旁白，-16 LUFS 左右，无背景音乐或极轻 |
| 字幕 | 关键步骤加中文字幕（便于评审静音观看） |
| 光标 | 保留并适度放大高亮，点击前停顿 0.5 秒 |
| 敏感信息 | 录制前遮盖真实 IP、密码、密钥、公司名 |

## 2. 录前准备（按顺序执行）

```powershell
# 1) 数据库与后端（:8080）
cd backend
mvn spring-boot:run

# 2) AI 服务（:8001，默认 mock 模型，无需密钥）
cd ai-service
python -m uvicorn app.main:app --host 0.0.0.0 --port 8001

# 3) 知识库服务（:8002，可选，用于演示检索）
uvicorn knowledge.server:app --host 0.0.0.0 --port 8002

# 4) 前端（:5173）
cd frontend
npm run dev
```

录前检查：

- [ ] 浏览器只开两个标签页：演示页 + 备用页，关闭无关扩展与通知弹窗（勿扰模式）。
- [ ] 演示账号已登录过一次，确认会话有效；密码输入框提前准备好粘贴文本。
- [ ] 演示用的图片证据已放在桌面（例如一张"Nginx 502"错误页截图）。
- [ ] 网络断开也不影响：确认 mock 模型可用（`ai-service` 未配置外部密钥）。
- [ ] 提前跑一次完整动线，确认每一步按钮位置没有变化。

### 01:10 – 02:40 场景一：故障问答（核心 AI 链路）

| 项 | 内容 |
| --- | --- |
| 画面 | 「AI 对话」页（`/chat`） |
| 操作 | ① 点击麦克风，语音说"MySQL 连接数打满了怎么排查？"（不支持语音的机器改用键盘输入，并在旁白说明这是渐进增强）② 点击"截取屏幕/上传图片"，选择桌面那张 502 截图 ③ 发送 |
| 旁白 | "我用语音描述故障，再附一张现场截图作为图像证据。注意：语音只在浏览器内转成文字，音频不出端；图片内容也不上传，只把文件名传给 AI 服务。" |
| 关键画面 | 思考阶段逐条点亮：**图像证据解析 → 知识检索 → 证据验证 → Agent 规划 → 风险判定 → 生成回答**；右侧正文流式输出；结束后展示引用来源与可信度评分 |
| 旁白 | "回答不是一个黑盒结论，而是六个阶段：先解析图像证据，再检索知识、验证证据，然后规划、判风险，最后才生成回答。下面这些引用和可信度评分，就是它敢被信任的理由。" |

## 4. 旁白节奏建议

- 每句话不超过 20 秒的量，留 0.5 秒停顿给画面切换。
- 不在画面上念代码；只念"这一步解决了什么问题"。
- 三个必须说出口的关键词：**证据、边界、留痕**。

## 5. 常见录制失误与规避

| 失误 | 规避 |
| --- | --- |
| 流式回答太快，思考阶段一闪而过 | 提前用较长问题（如"结合知识库说明排查步骤"），让阶段看得清 |
| 审批页空白（无待审批数据） | 录前先用一次 Agent 运行生成待审批项 |
| 知识版本对比不明显 | 录前准备两条同主题、不同版本的条目 |
| 终端测试输出滚太快 | 命令执行后停 2 秒再切画面，后期加定格 |
| 语音识别失败 | 直接改用键盘输入，并在旁白说明"当前设备不支持语音，已自动隐藏入口" |
| 视频超 8 分钟 | 场景三与场景四可合并剪辑，优先保留场景一与场景三 |
