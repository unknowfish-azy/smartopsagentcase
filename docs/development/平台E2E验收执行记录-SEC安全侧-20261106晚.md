## 四、过程发现（记录，非缺陷）

1. **登录后 CSRF token 轮换**：`AuthController.establish()` 调 `changeSessionId()`，
   会话重建后 CSRF token 更新。浏览器流程无感（前端每次 session 接口重取），
   脚本需登录后重新 `GET /api/auth/session`。E2E 已按此实现。
2. **沙箱环境变量 `SERVER__PORT` 会覆盖 `server.port`**：本机跑后端需显式
   `--server.port=8080`（或 `SERVER_PORT=8080`），否则可能绑定到意外端口。
3. **8002 端口曾有 11-05 的旧 knowledge 实例**（SEC-12 改造前代码、无 key 也能搜）：
   已杀掉并以新代码 + key 重启。**提醒：演示前若复用长期开着的 knowledge 进程，
   必须确认它是 SEC-12 之后的版本，且 `.env` 的 `KNOWLEDGE_API_KEY` 与 ai-service 一致。**
