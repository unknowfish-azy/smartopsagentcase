## 二、验收口径对照（清单 OPS-02）

| 验收项 | 证据 |
|---|---|
| 覆盖分页 | 两家适配器分别按 `Offset/Limit` 与 `offset/limit` 翻页，`nextCursor` 计算有测试断言 |
| 429 退避 | HTTP 429 读 `Retry-After`（秒），缺失时指数退避 + 抖动，重试次数上限可配；两家均有 `Retry-After: 1` → sleep 1000ms 的断言 |
| 权限不足 | 401/403 与腾讯响应体 `AuthFailure/UnauthorizedOperation` 归 `CLOUD_PERMISSION_DENIED`，`permissionDenied=true`，不重试 |
| 部分失败 | 任一页抛 `CloudProviderException` 即停止，服务层按 `pages>0 ? PARTIAL : FAILED` 记账，已取到的资源照常入库 |
| 资源 ID 稳定 | `providerResourceId` 取 `InstanceId`/`id`；地域统一用账号绑定值，可用区只进 metadata，避免可用区变化导致 uid 漂移 |
| 跨团队请求拒绝 | 沿用 `CloudAssetService.authorize`：团队账号非成员直接 403（既有测试覆盖） |
| 输出不含凭据 | `CloudCredentials.toString` 脱敏；两家适配器的异常文本、签名头均不含 secret，测试断言 `doesNotContain(secret)` |
