## 3. 关键设计

### 3.1 OPS-02 云连接契约

- **账号绑定**：`cloud_account` 保存 `provider + account_id + region + project_id + team_id + owner_user_id + credential_ref`。
  凭据只保存引用：`credential:<operation_credential.id>`（AES-GCM 解密，且必须是账号所有者本人）或 `env:<NAME>`。
  接口视图 `AccountView` 只回 `credentialRef`，任何路径都不返回 AccessKeySecret。
- **分页**：`PageNumber/PageSize`，以 `TotalCount` 判断是否还有下一页；单次同步有 `max-pages` 上限，超限按 `PARTIAL` 停止并保留已取到部分。
- **429/5xx**：优先 `Retry-After`，否则指数退避 + 0–25% 抖动，`max-attempts` 上限；耗尽后给 `CLOUD_RATE_LIMITED` / `CLOUD_PROVIDER_UNAVAILABLE`。
- **401/403**：立即归类 `CLOUD_PERMISSION_DENIED`（`permission_denied=true`），不重试，也不伪装成"空账号同步成功"。
- **跨团队**：个人账号只允许 owner；团队账号调用 `TeamResourceAuthorizer`，`view`/`run`/`manage` 分级，非成员直接 403。
- **扩展**：腾讯云/华为云在枚举中 `implemented=false`，同步返回 `SKIPPED + CLOUD_PROVIDER_NOT_IMPLEMENTED`，不会产生假清单。

### 3.2 OPS-03 轻量 CMDB

- **资源身份**：`resource_uid = provider:accountId:region:type:providerResourceId`，唯一索引；
  重跑同步只 UPDATE，不新建。
- **增量记账**：每次同步先建 `cloud_sync_run` 行，资源写入带 `last_sync_run_id`；
  只有"全量分页成功取完"才把 `last_sync_run_id` 不等于本次 run 的 ACTIVE 资源标为 `MISSING`，
  因此不依赖数据库时间戳精度，部分失败也绝不把资源误判为消失。
- **状态区分**：
  | 状态 | 含义 | 产生方式 |
  | --- | --- | --- |
  | ACTIVE | 最近一次成功同步命中 | 同步 upsert |
  | MISSING | 成功全量同步中消失 | 同步收尾 |
  | DELETED | 已删除 | 人工/事件显式标记，必须带证据 |
  | STALE | 采集过期（数据新鲜度不足） | 读取时按 `collected_at` 计算，不改写库内状态 |
- **关系**：`asset_relation(from_uid, to_uid, relation_type, source, evidence)`；
  `Declared` 关系必须填写证据（如变更单号），业务影响视图直接返回该证据；
  `MEMBER_OF/ROUTES_TO/HOSTED_ON/DEPENDS_ON/RUNS_ON` 覆盖主机、集群、数据库、负载均衡的建模需要。
- **业务影响**：`GET /api/cloud/business/{business}/impact?environment=` 返回按类型/状态计数、受影响资源、关系依据，
  以及"数据不完整"的账号清单（未同步、失败或部分失败），避免用过期数据下结论。

## 5. 复现方法

1. 绑定账号：

```bash
curl -X POST /api/cloud/accounts -H "Content-Type: application/json" -d '{
  "provider": "aliyun",
  "accountId": "1234567890",
  "displayName": "生产只读",
  "region": "cn-hangzhou",
  "credentialRef": "env:SMARTOPS_ALIYUN_AK"
}'
```

其中环境变量值为 `accessKeyId:accessKeySecret`，或改用 `credentialRef: "credential:<operation_credential.id>"`。

2. 同步并查看结果：`POST /api/cloud/accounts/{id}/sync` → `GET /api/cloud/accounts/{id}/sync-runs`
3. 业务影响：`GET /api/cloud/business/checkout/impact?environment=prod`
