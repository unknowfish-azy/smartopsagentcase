## 九、后续修改建议

### P0：解除 Dataset 阻塞

1. 导入可追踪的 REAL Agent Trace/日志，或明确标记的 SYNTHETIC Incident。
2. 补充 `source_type`、`source_ref`、环境、版本、证据、事故族和根因。
3. 执行 Schema、Quality、Safety、Duplicate、Leakage 检查。
4. 通过 Human Review 后才标记 `APPROVED`。
5. 生成非空 Train/Validation/Test Split 和 Leakage Report。

### P0：解除 Baseline 阻塞

1. 用户手动配置真实 Ollama 或 OpenAI-compatible Provider。
2. 配置真实 Evaluator 和 Ground Truth，不使用模型自评作为唯一依据。
3. 固定 Model、Prompt、Knowledge、Retriever、Reranker、Tool Policy 和 Dataset Version。
4. 先运行 Prompt Baseline，再运行 Real Baseline。
5. 保存输出、指标分子/分母、延迟、Token 成本和限制条件。

### P1：实验执行顺序

```text
Approved Dataset
→ Prompt Baseline
→ Real Baseline
→ RAG Ablation
→ Inspector Ablation
→ Verification Ablation
→ Benchmark
→ SFT
→ Preference Optimization
```

未运行的实验只能标记 `NOT RUN`，不能用 `0` 或假准确率替代。

### P2：训练环境

1. 在真实训练前补齐 Transformers、Datasets、PEFT、TRL，并重新执行 Readiness。
2. 没有 GPU 时只做 Dataset Validation、Baseline、Evaluation、Benchmark 和 CPU Dry Run。
3. 处理 `.pytest_cache` 权限 warning。
4. 启动 Backend、AI Service、Knowledge Service 后重跑 24 个 skipped。
