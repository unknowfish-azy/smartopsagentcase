## 已读本地项目的实际结论

前批 10 项包括 LangGraph、LlamaIndex、Qdrant、Phoenix、OTel Collector、StackStorm、Rundeck、Playwright、promptfoo、Alertmanager。它们是执行、检索、观测或评测工具，不能合称“10 个运维数据集”。根许可识别以离线核验 JSON 为准；它们没有证明任何关联数据可被训练或再分发。

本地 Phoenix README 的 `Copyright, Patent, and License` 明示 ELv2，现有根 LICENSE 原文也已保留；不是统一 MIT/Apache 处理的候选。README 的 tracing、datasets、experiments 能力说明只能支持“工具具有这些接口”的判断，不能证明已部署或已有可用标注。promptfoo README 明示 MIT、提供模型/提示词评测；它提供运行机制，测试数据仍须自建/审核。OTel Collector README 描述接收、处理和导出遥测，不能替代故障根因金标。

优先顺序：先审核 Loghub 单个小子集与我方日志格式，再审核 BEIR 单个子集做检索器对照；工具调用优先本地现有只读工具协议的隔离用例，外部 Agent 任务保持候选；OTel demo 等审批与资源明确后做隔离观测实验。Ragas、promptfoo 可评估为运行框架，但不新增正式样本数量。

## 统一入库与评测门禁

每个数据 artifact 单独登记 repository、commit、文件 blob/SHA256、下载来源、数据卡/专门条款原文、规模/语种/任务、允许用途、署名义务、再分发限制、个人信息、审核人和时间；任一许可或来源缺口保持 pending。根 LICENSE 缺失显式记录 unavailable，绝不推断允许。

训练、调参与独立测试按来源与时间分割，记录去重 hash；从当前 corpus/模型答案生成的样本只记 derived/regression。正式测试需要独立来源与人工 approved，保留 failure、partial、审批拒绝、恢复等分母，不筛除失败后报成功率。单列中文运维、日志解析、检索 Recall/nDCG、引用忠实度、工具参数/权限/状态正确性和故障恢复观测，禁止混成一个公开通用分数。

本批没有运行数据集基准、训练模型或正式采用外部语料。公开 benchmark 分数、框架自报结果以及离线单元测试通过率均不是 SmartOpsAgent 的准确率。
