# 独立评测数据治理

`data/evaluation/independent-v1/` 是本批 loopback CONTROLLED 观测集，含 8 个边界场景、原始 probe、samples 和冻结 manifest。样本可由 AI 编写，但 `label_status=pending_review`，trusted-host 人工批准数为 0。

评测前必须核验 manifest、samples 和每个 evidence 的 SHA256；从训练记录重新计算 input 与 incident_family 重叠，不能信任 manifest 字段。重复 ID、路径逃逸、候选派生 Golden、样本自审批和篡改均 BLOCKED。formal 指标只有在人工审核、独立训练证据和逐样本预测都齐备时计算，否则 `accuracy=None`；regression 单独标记，不代表生产准确率。

采集脚本仅绑定 `127.0.0.1` 临时 HTTP 服务，记录 200/401/403/502/504、404 和超时，不访问在线生产地址，不执行系统动作。

## 独立审阅修正
