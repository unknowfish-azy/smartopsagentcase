# 联网研究 · 长期压力观测执行说明（T35c）

> 目的：把"长期多来源压力行为"变成可观测、可核验的运行时数据。本说明只定义**怎么测、看什么**，
> 不宣称任何泛化结论；所有观测报告必须标注"本环境样本，不宣称泛化"。

## 1. 暴露的指标（/actuator/prometheus）

| 指标 | 含义 | 假繁忙红线 |
| --- | --- | --- |
| `smartops_webresearch_radar_due` | 每轮扫描发现到期来源的次数 | 无到期即零 |
| `smartops_webresearch_radar_processed` | 实际领取并执行（含失败）的轮次 | 无执行即零 |
| `smartops_webresearch_radar_skipped` | 被其他副本 claim 领取而跳过的次数 | 无竞争即零 |
| `smartops_webresearch_render_duration` | JS 渲染耗时 Timer（p50/p95 由 prometheus 聚合） | 无渲染即无样本 |
| `smartops_webresearch_snapshot_written` | 快照写入次数（检索正文 + JS 渲染） | 无写入即零 |
| `smartops_webresearch_retention_deleted` | 保留策略删除的旧快照数（默认关闭，显式开启才有值） | 未开启恒零 |

## 2. 采样方案

1. **窗口**：连续观测 ≥72 小时（覆盖至少一个完整的雷达扫描周期与多次快照写入）。
2. **并发来源数**：≥3 个 `monitor_enabled` 来源、`monitor_interval_minutes` 取默认 60；
   观测期间不调整配置（调整即作废当轮窗口）。
3. **抓取方式**：`GET /actuator/prometheus` 每 15 秒采样一次，原始数据落
   `.runtime/web-research-observation/<日期>/prom-<时间戳>.txt`。
4. **对照组**：观测开始与结束各记录一次表规模基线
   （`web_research_page` / `knowledge_crawl_page` 行数、库文件体积）。

## 3. 观察结论字段（报告模板）

- 样本量与窗口（起止时间、采样条数）；
- `render_duration` p50 / p95 / max；
- 雷达 processed/skipped 比例（多副本竞争健康度）；
- 快照增长速率（行/小时）与开启保留策略后的回收量；
- 失败率：`web_research_task` 中 status=FAILED 占比（按 error_code 分组）；
- 内存：观测期 JVM 堆使用（actuator/metrics/jvm.memory.used）采样极值。

## 4. 边界

- 报告**只呈现数字与窗口**，不下"系统可支撑 X 规模"的推断；
- 不在报告中出现任何"准确率""可信度评分"字样；
- 观测不改变任何数据正确性语义（claim/UNCERTAIN 行为与单副本一致）。
