## 三、Candidate 状态机

```text
CANDIDATE → VALIDATED → QUALITY_CHECKED → SAFE → REVIEW_PENDING → APPROVED
```

失败状态：`INVALID / UNSAFE / DUPLICATE / LEAKAGE / REJECTED`。

只有以下条件全部满足才允许 `promote()`：`candidate.state=APPROVED`、`review.status=APPROVED`、`sample.quality.human_review=APPROVED`。自动生成 Candidate 不会自动进入训练集。
