## 0. 一分钟速览（Executive Summary）

**智维Agent** 是一个面向中小企业的**可信 AI 智能运维与知识协同平台**。它把"监测 → 分析 → 知识检索 → 证据验证 → 决策规划 → 风险判断 → 人工审批 → 安全执行 → 结果验证 → 审计留痕 → 经验沉淀"十一环连成闭环，让大模型从"会回答运维问题"变成"敢把生产环境交给它、且每步可追溯的 AI 同事"。

核心差异不在模型，而在**三道关口**：

- **证据**：版本感知混合检索，回答里每句话都能点回具体知识条目与版本；
- **边界**：AI 负责思考、人负责授权、系统负责执行，高危动作必须人工审批；
- **留痕**：四级核查 + 恢复契约 + 全程审计，"假成功"逃不过状态核验。

四端全栈可运行、默认 mock 零密钥跑通、本地 Ollama 可复现。规模：Java 后端 331 文件/3.69 万行/477 接口/119 表，Vue 前端 234 文件/3.9 万行，Python 22,048 行；三层测试前端 733 / Python 622 / Java 774 项，最近一次回归 0 失败。

## 1. 项目定位

### 1.1 真实痛点

中小企业运维的三个常态：**人手少、系统杂、知识散**。

| 现实痛点 | 现有方案的不足 |
|---|---|
| 知识散落在聊天记录、老员工经验、历史工单 | 搜索引擎按关键词命中，常返回**过期版本** |
| 故障定位依赖个人经验，新人上手慢 | 通用问答机器人给不出**可核对的证据链** |
| 大模型能"说"不能"做"，做了没人敢用 | 缺风险分级、人工审批、审计留痕 |
| 一次误操作可能造成生产事故 | 通用 Agent 工具默认权限过大 |
| 处理过程无法复盘 | 操作无结构化记录，经验无法沉淀 |

### 1.2 一句话定位

> 把大模型能力约束在"证据驱动、风险可控、全程留痕"的闭环里，让 AI 从"会回答运维问题"走向"可信地完成运维任务"。

### 1.3 目标用户与场景

- **目标用户**：10–200 人规模企业的运维负责人、驻场工程师、技术负责人；高校实验室、实训机房。
- **核心场景**：①故障问答与定位；②版本感知知识检索；③受控执行；④结果核查与经验沉淀；⑤团队协同。

### 1.4 与评分维度的对齐

竞赛 AI 技术分项权重 35%（LLM 8 + Agent 8 + RAG 6 + 多模态 5 + 安全 4 + MCP 4，fact-sheet F09），本项目逐项对应：LLM 网关可切换、Agent 五模块、混合检索与证据、Three.js/ECharts/语音多模态、风险策略与人工审批、MCP 适配器。

## 5. 可信闭环：三道关口

### 5.1 第一道 · 证据（查得对版本、答得有出处）

运维知识最痛的不是查不到，而是查到旧版本。版本字段随每个知识切片打标，检索按目标环境过滤；BM25 + 向量双路召回按 0.6:0.4 融合、重排取前 5；每条证据的来源、版本、支持度聚合为可信度评分 `trust_score`。回答里的每句话都能点回具体条目。

### 5.2 第二道 · 边界（AI 思考、人授权、系统执行）

Agent 把故障拆成带依赖的步骤；策略引擎按权限与风险给每个动作定级；重启服务、改配置这类高危动作必须转入人工审批，批准后才在沙箱与命令黑白名单约束下执行。**高危动作故意不在演示中绕过审批直接执行**——安全是架构逼出来的，不是演示出来的。

### 5.3 第三道 · 留痕（四级核查 + 恢复契约）

- **四级核查**：L1 规则查风险分级与循环调用；L2 证据查版本一致性；L3 可选大模型判定；L4 状态核验抓"假成功"——Agent 声称"已重启成功"但探针事实显示服务没起来，即判不通过并重新规划。
- **恢复契约**：目标、版本、新鲜度、轮次、来源全部达标才算真恢复。冻结案例中，弱基线（"任意 200 就算恢复"）产生 21 次假恢复；我们的实现**假恢复 0 次**，与独立 oracle 判定高度一致（保守口径 41/42，见 `recovery-contracts/claim-matrix.md` #6）。

## 6. 创新点

答辩只深讲最核心的 3 个，其余一句带过（评委要"深"不要"多"）：

1. **可信闭环工程化**（核心）：把权限、风险、审批、核查、审计做成**可运行的代码路径**，而非文档理念——从"AI 对话"到"AI 运维"的关键一跃，每个点都有代码位置与演示路径。

5. **多模态隐私边界**：图像仅文件名级参与、语音不出端，不把"传文件名"包装成"看懂图片"。
6. **插件化工具 + 可切换模型网关**：MCP 适配器、mock/Ollama/OpenAI 兼容运行期切换。
