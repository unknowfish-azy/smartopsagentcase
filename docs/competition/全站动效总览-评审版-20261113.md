## 0. 30 秒电梯陈述

这套前端不是「会动的壁纸」，而是一套**三层动效体系**：背景负责氛围，**数据负责叙事**，交互负责反馈。
评审能在不读任何文字的情况下看懂三件事——**AI 正在思考、数据正在流动、系统状态正在变化**。
所有动效都挂在统一的降级门禁上：系统开「减少动态」、页面切「轻量/减少动态」、设备掉帧、窄屏，任一条件命中即自动收敛，功能与可读性完全不受影响。

---

## 1. 三层体系

```
L3 交互层  hover 抬升 1px · 150ms 微交互 · 路由转场 · 侧栏 active 脉冲 · Cmd+K
           └─ 告诉用户「我的操作被接收了」
L2 数据层  KPI 数字滚动 · 网格错峰入场 · 图表入场/更新 · AI 逐行揭示 · 执行轨迹状态点亮
           └─ 告诉评审「AI 在思考、数据在流动」（本轮重点建设）
L1 氛围层  星网 Canvas · 极光漂移 · 流星 · 星尘舞台 · 封面视频槽（预留，当前为静态 poster）
           └─ 负责质感与品牌，不承担信息表达
```

工程上对应两个全局样式文件：`motion-layer.css`（克制基线，默认生效）与 `motion-strong.css`（强效果档，仅「平衡视觉」生效），加上各页面自有的 canvas/组件动效。**新增一处动效不需要再写 keyframes**，挂语义类即可。

## 3. 降级与性能（这套体系敢开强的底气）

| 触发条件 | 行为 |
|---|---|
| 系统 `prefers-reduced-motion: reduce` | 全站 `animation/transition` 归零，ECharts 同步 `animation:false` |
| 页面切「轻量视觉 / 减少动态」 | 强效果层整层不生效；减少动态时基线层也停用 |
| 运行时掉帧（`motionScheduler` 置 `data-motion-degraded`） | 全部动效自动停用 |
| 窄屏 `<768px` | 仅保留 AI 流式光标与状态点，其余停用 |

两条刻意保守的设计：

- **KPI 数字只滚一次**（首屏）。之后数据刷新直接更新，不让看板一直闪。
- **canvas 动效单独接降级**。CSS 的 reduced-motion 够不到 ECharts，三处图表都从 `motionQuery` 取信号，命中即整段关闭。

## 4. 演示动线（约 6 分钟）

1. **登录页**（30s）：保持「平衡视觉」，指出星尘/极光/流星与玻璃卡光晕；随后在下拉框切「轻量视觉」再切「减少动态」，同一页面三级反差，一句话带过「动效是可关的，不是强行炫技」。
2. **首页**（60s）：刷新页面，让评委注意 **KPI 数字滚动**与卡片的错峰入场顺序；指向拓扑与图表的入场动效。话术重点：「数据层动效，不是背景动效」。
3. **执行轨迹**（90s）：逐步指出四步链状态、连接器传导、星底极光。这是 AI 能力最直观的一屏，值得停留。
4. **AI 对话**（60s）：发一条指令，展示思考时间线与回答的逐行揭示。话术口径为「思考过程可见、输出有节奏」；**不要说成「逐 token 生成动画」**——逐行揭示是回答完成后按行重排，流式期间另有光标提示。
5. **告警中心 / 洞察页**（45s）：快速带过列表错峰与图表逐项入场，说明全站复用同一套编排层。
6. **无障碍收尾**（45s）：切「减少动态」或打开系统减少动态，全站动画归零而功能不变；报出 a11y 实测结果（见 §6）。

## 5. 与评分维度的对应

按 `前端动效大调整-…方案-20261113.md` §2.3 的口径估算，**AI 交互体验 + 前端交互体验 + 交互创新**合计约 13% 的分值直接受「动效是否传达 AI 在思考、数据在流动」影响。
本轮建设正是把动效从背景层推进到数据层与内容层，针对的即是这部分分数；同时用降级门禁守住「性能与可用性」不失分。

## 7. 边界与诚实说明

- 五个抖音参考链接在 Web 端均被反爬（返回「请在抖音内观看」），**未获取任何视频画面**；落地的是「标题/描述 → 设计语义」的转化，不是逐帧复刻。
- 强效果档只在「平衡视觉」生效；评审机器若性能较弱，系统会自动降级，演示时建议先确认当前视觉模式。
- 无障碍自动化覆盖 axe/溢出/焦点/动效，**人工读屏与真实设备复核仍需人工完成**。
- 运维语境沿用「红=故障、绿=健康」的状态色，未套用参考素材中的股票涨跌配色，避免语义错乱。
- **未取得任何平台素材授权**：全部动效为自制 CSS / Canvas / ECharts，未下载、搬运或内嵌任何第三方视频、GIF、封面；登录页封面视频槽当前空置，后续若接入素材须先完成授权或可商用来源核验。
