> 口径约束（四条硬边界）：
> ①**非 LLM**：模型成分是确定性 `InspectorPipeline`（Rule+Evidence+AI降级+StateVerifier），`is_llm=false`，不得写成模型能力。
> ②**数据集未批准**：受控集全 `review_status=unreviewed` / `human_review=PENDING`，**approved=False**，本结果不得引用为「approved 基准」。
> ③**词表已补齐陈述式断言（2026-11-20）**：原词表仅覆盖「动作完成 + 恢复」两类措辞，144 条中 84 条落 unknown；补入真实措辞后 **unknown 归零**，可判子集由 n=10 扩至 n=22。未覆盖措辞仍 fail-closed 落 UNKNOWN，否定优先规则不变。
> ④翻译忠实性已达 **1.0000（144/144）**；此前的 0.8125 根因已逐条定位并修复（systemd `active` 缺失、metric 极性反转、语义位缺失），**不是**随机误差。该指标度量「归一化健康度与真值 SUCCESS 是否一致」，**不等于**真实分布准确率。
> ⑤**claim 语义歧义**：`denies_success` + 探针不健康时核验器判 `passed=True`，脚本映射为 SUCCESS；此类 claim 可能是「故障仍在」也可能是「否定式正面陈述」（如「配置不再漂移」真值 SUCCESS），故全样本一致率 0.5000 仅作参考，**不可用于断言分类准确率**。
> ⑥**二分类子集口径（2026-11-21）**：P/R/F1 只在「claim=asserts_success 且真值 ∈ {SUCCESS, FALSE_SUCCESS} 且预测 ∈ {SUCCESS, FALSE_SUCCESS}」的子集上计算；真值为 FAILED/UNKNOWN 的可判样本**单独计数披露**（test 0 条、validation 4 条），**不进 P/R/F1 分母**——否则准确率与 P/R 会互相矛盾。
> ⑦**消融统计口径（2026-11-21，M29）**：根因消融全部在**合成图谱**（随机拓扑 + 合成告警）上，结论只说明「模型在该生成器下的相对优劣」，**不得**写成真实生产性能；seed=**8**（<10），分层 bootstrap 在每个 seed 内重采样事件但**层数过少、seed 间方差仍估计不足**，区间不得写成高精度；`large_graph` 场景**无任何模型在 Holm 校正后显著优于 `heuristic`**（gat raw p=0.0135 方向为负 → Holm 0.0677），**不得**声称大图存在可用模型或「GraphSAGE 为大图首选」。
> ⑧**分组相关口径（2026-11-21，M30）**：受控集 test 的 48 条**组内判定完全同质**，主终点二分类子集 n=22 **只覆盖 4 个 `root_cause_group`**，**有效样本量上界为 4**。因此：①M20/M26/M27 的 Wilson 区间**偏窄**，引用时必须同时给出「有效 n ≤ 4」；②**不得**用 ICC=1.0000 宣称「已证明样本独立相关」——组内方差为 0 令区间退化，只可说「样本内无组内变异可估」；③扩样本必须**增加 `root_cause_group` 数量**而非仅增加变体，否则有效 n 不增长。
> ⑨**效度红线（2026-11-21，M31/M32，最高优先级）**：**主指标子集的真值标签可由「探针健康度」单比特唯一决定**——全量 144 条中探针健康 ⇒ `SUCCESS`、不健康 ⇒ `FALSE_SUCCESS`/`FAILED`/`UNKNOWN`（列联完美对角，Fisher 精确单侧 p≈9.1e-13）；在主指标二分类分母（n=72）上平凡规则「不健康 ⇒ FALSE_SUCCESS」复现 **72/72**，反极性对照 **0/72**。含义：`EXP-BASELINE-001` 的 P/R/F1=1.0000 **不需要任何 claim 语义理解**，等价于 `prediction = f(probe_health)`，而标签本身由同一输入构造 → **循环论证**。因此：①**禁止**把 M20/M26/M27 的任何 P/R/F1 写成「假成功检测能力」证据，只能写成「探针归一化链路自洽性」证据；②生成器 `LABEL_CONTRACT`（`build_controlled_dataset.py:519`）已自陈「标签由探针断言直接推出」，DATA-CARD 亦声明合成性质，**这不是数据造假，而是指标被误用为能力证据**；③修复前提是引入**对抗单元**（探针健康但标签非 SUCCESS / 探针不健康但标签 SUCCESS），并由独立观测或人工判定产生标签。

> ⑬**ASR 口径（2026-11-22，M35/F14）**：DTW 与 faster-whisper 是**两条不同链路**，数值不得混填。①**DTW 83.33%/80.00%** 只成立在 **refA 合成冻结集**（24kHz，模板与数据同一 TTS 分布）上，**禁止**写成「真实语音 80%」——真实人声**命令词**语料缺失，未验证；②**禁止**称「自由听写可用」——合成集上 base 3.33% / medium 10.00%（holdout），真实人声 41 条 medium 平均 CER 0.246、完全命中仅 12.20%；③**必须说明**采样率修复已端到端复验（旧 8kHz / 2.91s 损坏集 → 新 24kHz / 0.80~0.99s）；④不同模型规格（base/medium）结果**不得互相覆盖或混填**。
> ⑭**视觉 OCR 口径（2026-11-22，M36/F25）**：视觉侧 OCR 已落地（RapidOCR，中文 + 英文），但两组数字性质不同：①**受控渲染样本**（已知真值）CER 0.0000 / 完全命中 1.0000 **只证明链路正确**，**禁止**写成「OCR 准确率 100%」；②**真实文档截图**的 0.9216 是**宽松子串命中**（真值取文档全文而非该页逐字），**禁止**写成「准确率 92%」，且已发现真实错字（「洞察」→「润察」）与页码错误；③`desktop-perceive` 的 OCR 增强**默认关闭**，开启后 `ocr_text` **不参与 `element_id`**（保持既有 id 契约）；④引擎缺失时返回 `available=false` + 原因，**禁止**用 VLM 描述冒充 OCR 结果。
> ⑮**情绪识别口径（2026-11-22，M37/F26）**：P2-8「情绪识别输入」已落地，但**只覆盖文本输入**（输入框或 ASR 转写），**不是语音情绪识别**。因此：①**禁止**把受控文本集逐句命中 0.5600（n=25）写成「情绪识别准确率 56%」对外能力声明——它是**人工构造的已知标签集**，只证明链路可用；②**必须同时说明**所选模型 `IDEA-CCNL/Erlangshen-Roberta-110M-Sentiment` 是**情感极性二分类**（`id2label={0:Negative,1:Positive}`），只输出 happy/sad，`neutral` 0/5 与 angry/surprised 各 2/5 是**维度错配的已知失败**，不得写成模型「大部分正确」；③**禁止**引用模型卡上的 97.77/97.31/96.61（那是作者的情感分析基准，与本评测无关）；④引擎不可用 / 低置信 / 未知标签一律**不叠加**并如实标注来源档位，**禁止**用 VLM/LLM 描述冒充情绪模型结果；⑤告警（warning）/ 故障（error）状态下情绪**不改变**状态语义。
> ⑯**多 Agent 辩门口径（2026-11-22，M38/F27）**：P2-7 / A 已落地**协议与隔离**，但**未证明辩论协议本身带来增益**。因此：①**必须同时报告覆盖对照**——把全量证据一次性给同一角色（无辩论）。test 上辩论与覆盖对照**逐样本 0/48 不同**，train/validation 上辩论因未收敛**反而更低**（0.6875 vs 0.8125 / 0.7500）；故相对单角色的增益**全部来自四通道证据覆盖**，**禁止**写成「多 Agent 辩论提升准确率 X%」；②角色是**离线确定性规则**（`RuleRoleAgent`）+ **人工按探针语义拟定的封闭候选词表**，**不是 LLM**，也**不是**从数据学出的模型，故准确率只反映**命名/语义一致性**，**禁止**写成「AI 根因识别准确率」；③受控集为**合成 fixture**且 M31 已判定存在「标签—探针循环」，`evidence_precision=1.0000` 属**循环指标**（引用证据按支持真值挑选），**不得**当作辩论质量证据；④`escalated` 一律记为**无结论**并**单独计数**，**禁止**从分母剔除或粉饰成「达成一致」；⑤`n` 与**有效 n** 必须同时给（本实验有效 n 远低于名义 n：test 8.0 / train·validation 9.1915）；⑥真实 LLM 角色路径**未接入**（`RoleAgent` 已留注入点），**禁止**写「LLM 多智能体辩论」或「多模型辩论」。

> ⑰**知识图谱口径（2026-11-22，M39/F28）**：P2-7 / B 已落地**词表 + 抽取 + 图存储 + 符号推理 + 对照评测**，但**未证明符号侧带来独立的召回增益**。因此：①**金标由图派生**（`gold(A)` = 与 A 共享 `caused_by` 根因的条目 ∪ `cites` 目标），KG 候选来自**同一份图** → **KG 的 hit@5=1.0000 与 hybrid+KG 的 +0.0408 增量都是循环的**，**禁止**写成「混合检索优于 hybrid」「KG 提升召回 X%」；②覆盖率**必须给两个口径**——「有任意入图边 **737/737 = 1.0000**」是因为声明式 `emits` 覆盖全部条目、**无信息量**，有意义的数字是**有 `caused_by` 边 319/737 = 0.4328**；**禁止**写「全量知识图谱」；③**入图边抽样核对（24/24）与抽取器共享词表**，属**自检**，不证明语义正确；被拒边核对（24/24）判据独立，但只验证阈值策略未误杀；④**召回层是 HashEmbedding**（确定性哈希向量，**非语义模型**），hybrid 的 recall 只是**召回层基线**，**禁止**写成「语义检索性能」；⑤无 `caused_by` 边的告警一律标 `neural_only`，**禁止**写「符号推理得出」；⑥被拒边（**217 条**）一律不计入任何命中。
