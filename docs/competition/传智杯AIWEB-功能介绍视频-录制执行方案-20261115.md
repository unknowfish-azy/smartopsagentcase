## 0. 一句话结论

**模板 = 深色全屏浏览器录屏 + 每句一屏底部白色粗体中文字幕 + 本人原声旁白 + 硬切 + 20fps。**
新片沿用这套壳，把内容从「41 句走一遍功能页」扩成「从登录页开始的 42 镜全站特效巡礼」，素材不限时长，成片统一 1.5 倍速；旁白以**复用模板原声**为主、新增镜头用**克隆音色**补齐，保证整片听起来都是同一个人的声音。

> ⚠️ 时间约束：省赛作品提交截止 **2026-11-18**，今天是 11-15。本方案按「先出一支可交付成片，再迭代」排优先级，不要在完成前陷入工具链安装。

## 2. 待拍板的三项决策

### D1 · 配音路线（**硬阻塞，必须先定**）

| 路线 | 做法 | 优点 | 风险/代价 | 建议 |
| --- | --- | --- | --- | --- |
| **A 原声复用 + 克隆补齐** | 从模板 mp4 按 41 条 srt 切出原声片段建语料库；新片 70% 句子直接复用；新增约 20–25 句用克隆音色生成 | 100% 是你的声音、零整段重录、音质稳定、最快 | 需装一次克隆链路（约 20–25 句） | ✅ **推荐** |
| B 全量本地克隆 | 装 CUDA torch + CosyVoice2 / F5-TTS（经 hf-mirror 下 3–6 GB 权重），全部文案重生成 | 音色/音量/语速完全统一 | 下载量大、依赖多（torch CUDA / funasr / whisper），国内源可能失败；8 GB 显存够但首次编译慢 | 备选 |
| C 云端克隆 API | MiniMax / 火山 / 阿里百炼 音色克隆 | 效果最好、无需本地 GPU | **需你提供 API key**，且音色克隆通常需实名/付费 | 需你授权 |
| D 你补录新增句 | 我给逐句稿 + 精确到秒的时间轴，你照读录音，我做切句对齐 | 最真、零技术风险、零成本 | 需要你花约 10 分钟录音 | 保底降级方案 |

> **降级链**：A 的克隆安装失败 → 自动退到 D；B/C 未授权不启动。

### 4.1 浏览器录制（Playwright Python 1.64）


### 4.2 配音与字幕

1. **原声语料库**：`ffmpeg -i 模板.mp4 -vn -ac 1 -ar 44100 template_voice.wav`；先跑 `silencedetect` 确认句间为静音、无 BGM；再按 41 条 srt 的 `start/end` 用 `-ss/-to` 切成 `voice_R01.wav … voice_R41.wav`（每片首尾各留 80ms，避免切掉辅音）。
2. **新增句**（按 D1 路线）：逐句稿定稿后生成 `voice_N01.wav … voice_N22.wav`，统一 **44100 Hz / 单声道 / -16 LUFS**。
3. **拼接**：按分镜顺序 concat，句间插 120ms 静音；全轨 `loudnorm=I=-16:TP=-1.5:LRA=11`；导出 `narration.wav`。
4. **字幕**：生成 `.srt`（素材时间轴），一条一句、不跨镜；样式复刻模板：
   ```
   [Script Info] ScriptType: v4.00+  PlayResX:1920 PlayResY:1026
   [V4+ Styles] Style: Default,Microsoft YaHei Bold,36,&H00FFFFFF,&H00000000,
                &H00000000,&H00101010,-1,0,0,0,100,100,0,0,1,2,1,2,24,24,28,1
   ```
   白色粗体 / 黑描边 2px / 轻阴影 / 底部居中 `MarginV=28` / 无底条。
5. **时间轴**：**成片时间码 = 素材时间码 ÷ 1.5**。字幕按成片轴生成后再烧录，避免加速后字幕错位。

### 4.3 合成与 1.5 倍速

```bash
# 1) 逐镜拼接（硬切，与模板一致）
ffmpeg -f concat -safe 0 -i shots.txt -c copy raw_video.mp4

# 2) 统一 1.5 倍速：画面 setpts + 音频 atempo（atempo 不变调，原声复用不会变尖）
ffmpeg -i raw_video.mp4 -i narration.wav -filter_complex \
  "[0:v]setpts=PTS/1.5,fps=20[v];[1:a]atempo=1.5,loudnorm=I=-16:TP=-1.5:LRA=11[a]" \
  -map "[v]" -map "[a]" -c:v libx264 -crf 20 -preset medium -pix_fmt yuv420p \
  -c:a aac -b:a 192k -ar 44100 -movflags +faststart base.mp4

# 3) 烧录字幕（按成片轴）
ffmpeg -i base.mp4 -vf "subtitles=final_1p5x.ass:fontsdir=C\\:/Windows/Fonts" \
  -c:v libx264 -crf 20 -preset medium -c:a copy -movflags +faststart \
  智维Agent_传智杯AIWEB_功能介绍_1.5x.mp4
```

- **不要**用 xfade 转场（模板是硬切）；片头片尾若要加，各 ≤2s 纯文字卡，且必须先加速再烧字幕。
- 输出规格对齐模板：**1920×1026 / 20 fps / H.264 / AAC / bt709**；如赛事要求 1920×1080，用 `pad=1920:1080:0:27:black` 补边，不要拉伸。
- 备选：画面若需更平滑可用 `minterpolate`，但会显著拖慢合成且可能产生伪影，默认不用。
