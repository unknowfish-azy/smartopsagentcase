## 5. 工程落地约束（本方案最关键的一节）

### 5.1 硬冲突：不能无脑加 `<video>`
项目已内建三档视觉预算（`visualMode.js:3`）与自适应降级（`:38-51`）。若视频无条件加载，会直接：
- 破坏 `lightweight` / `reduced-motion` 档的语义（用户选了「减少动态」却还在播视频）；
- 违反 WCAG 2.2.2（超过 5 秒的移动内容必须提供停止方式）；
- 拉低 T11 已验收的 Lighthouse 桌面 92 / 移动 95；
- 与 `login-glass` 契约冲突 —— 该契约此前曾被 `.login-form` 的 `transform: scale(1.004)` 打断，**新增背景层不得改变表单几何、层级或 blur 值**（控制台 blur=0 基线）。

### 5.2 正确的接入位（交实现模型）
- 视频作为**最底层氛围层**（`z-index` 低于 `CanvasAmbientField`），仅 `v-if="visualMode === 'balanced'"` 时挂载；
- `poster` 直接复用现有 `public/assets/starfield-placeholder.svg`（零新增资产）；
- `lightweight` / `reduced-motion` / `adaptiveVisualBudget()` 判为降级时，**根本不创建 video 元素**，只留现有 Canvas 星野；
- 叠加 40–60% 暗色遮罩，按「最亮的一帧」而非「最暗的一帧」验证对比度；
- 移动端（<1024）默认不加载视频，只出 poster —— 与 `adaptiveVisualBudget()` 的 `narrow` 判定一致；
- 禁止外链托管，**必须下载后本地化**（竞赛评审环境可能断网，且外链有防盗链/失效风险）。

## 6. 推荐结论与落地包

### 6.1 首推
**① Pixabay 250385「Abstract Blurry Blue Loop」** —— 它就是截图里那道斜向冷光带的「会动的版本」，深蓝、无物象、慢、不抢字，且授权最干净。
备用：**② Pexels 7101913**（想要可见粒子流时）、**③ Pexels 7198205**（想要最暗最静时）。

### 6.2 诚实的第二意见（REA：局限必须说明）
按 GitHub 首页设计拆解的反证与本项目现状，**视频未必是最优解**：现有 `CanvasAmbientField` 已经是矢量、可交互、体积近零、能响应三档视觉预算的方案；视频反而带来 2–4MB 体积、无法按性能分级、无法交互。
若你的真实诉求只是「画面不僵硬」，**更低风险的替代**是给现有 Canvas/CSS 星野加一层**大尺度缓慢漂移的极光光带**（SVG 渐变 + CSS `transform`，约 0 KB、天然支持 reduced-motion），完全不碰 T11 性能基线。
建议：**省赛（11-18 截止，仅 5 天）走替代方案**；视频层留到国赛前作为「可选氛围增强」再做 A/B 对比。
