## 1. 落位判定（为什么是"导航最下面"）

按 `frontend/src/navigation/personalSystemNavigation.js` 的渲染顺序：

```
HOME · AI CHAT · INSIGHTS · TEAM SPACE · 知识库 · CLOUD NATIVE · PLUGINS · SKILLS
· 连接中心 · HARBOR · OPERATIONS · HEALTH CENTER · MILESTONES · MODELS(组)
· AGENT(组) · MEMORY(组) · SENTINEL(组) · ADMIN*  · ARCHITECTURE*
                                                        * = roles:['admin']
```

- **operator**：最后一个可见组 = `SENTINEL`；组内最后一项 = `GUARDIAN`（守护 Agent）。→ 把预测面放在 SENTINEL 末尾，operator 的导航最下面就是它。
- **admin**：其后还有 ADMIN、ARCHITECTURE，最底部是架构总览。

**推荐方案 A（本包采用）**：`SENTINEL` 组最后一项。理由：
1. 预测属于"哨兵在看"的能力，不是模型接入能力；
2. operator 的底部正好是它，符合"导航菜单栏最下面那个界面"的直觉；
3. 与守护 Agent 相邻，形成"阈值建议 → 预测越界"的连续阅读。

**备选方案 B**：`MODELS` 组末尾（路由 `/forecast`）。只有当你认为"预测是模型能力、应由模型中心承载"时才选它；改动量相同，见 §3.2。

### 1.1 与既有页面的职责边界

| 页面 | 管什么 | 本页不做什么 |
| --- | --- | --- |
| `/sentinel` 哨兵监控台 | 现在的采集与告警 | 不重复展示告警列表 |
| `/sentinel/guardian` 守护 Agent | 学基线、出阈值建议 | 不改阈值、不写回 |
| `/sentinel/alerts` 告警中心 | 处置告警 | 预测越界不自动建告警 |
| `/model-strength` 模型强度 | LLM 调用可用性 | 不复用 LLM 指标 |
| `/agent/trace` 执行轨迹 | Agent 推理链 | 不重复挂神经网络动效 |

## 4. 数据契约与三态

### 4.1 接口（建议，TRAE 只写前端适配层）

```ts
GET /api/sentinel/forecast?metric=ect&horizon=30
{
  generatedAt: string
  model: { version: string, arch: 'MLP+GRU', params: number,
           metrics: { mae: number, rmse: number, mape: number },
           trainedAt: string, epochs: number, gate: 'PASS' | 'FAIL' | 'PENDING' }
  points: Array<{ t: number, median: number, p10: number, p90: number }>
  crossings: Array<{ kind: 'warn' | 'crit', h: number, value: number, confidence: number }>
  unit: string
}

GET /api/sentinel/series?metric=ect&window=180
{ points: Array<{ t: number, v: number }>, unit: string }

GET /api/sentinel/forecast/models
{ models: Array<{ version: string, gate: string }> }
```

- 字段缺失 = 不可用，**不补默认值**；`points` 为空时整块显示空态。
- 单位随接口返回，前端不换算。
- 所有请求走 `utils/request`（自动带 `X-Request-ID` / CSRF）。

### 4.2 四种状态

| 状态 | 触发 | 界面 |
| --- | --- | --- |
| `loading` | 首次请求 | 骨架块（静态，不闪烁）；工具栏可用但禁用切换 |
| `live` | 接口 200 且 `points` 非空 | 正常渲染 + `LIVE` 角标 |
| `demo` | 用户点"查看演示数据集" 或 接口不可用但用户选择演示 | `DEMO · 虚构示例` 角标 + 页脚声明；数据来自 `syntheticSeries.js` |
| `offline` | 401/503/网络错误且未选择演示 | 主图空态 + 说明 + "查看演示数据集"按钮；所有数值 `—` |

**演示数据的硬要求**：模块导出的每个序列带 `demo: true`；页面角标与页脚各声明一次；**禁止**把演示数据写进任何持久化、任何图表导出、任何截图脚本之外的产物。

### 4.3 演示数据生成

- 确定性：`mulberry32` 种子 + 正弦叠加 + 慢漂移，同参数同输出。
- 6 个传感器：ECT/RPM/EGT/OILP/IAT/VBAT，阈值与单位随传感器定义（见设计稿 `SENSORS`）。
- 预测：`v0 + slope·阻尼·h + 回归项`，区间宽度 `∝ √h`（只用于把"越远越不确定"画出来）。

## 5. 实现要点

1. **Canvas 而非 ECharts**：本页需要"区间 + 阈值 + 游标 + 越界点 + 残差条"的一体化绘制，ECharts 的 markArea/series 组合会带来 3 个 canvas 和一套主题冲突。用单 canvas + `ctx.setTransform(dpr,…)`；`ResizeObserver` 重算尺寸；`devicePixelRatio` 变化时重建。
2. **一个 rAF**：通过 `src/visual/motionScheduler.js` 订阅（`fps: 30`，`id: 'forecast-playback'`），暂停或 `document.hidden` 时退订；不要在组件里裸写 `requestAnimationFrame`。
3. **重绘只在必要时**：数据、视野、主传感器、影子开关、游标位置变化才 `draw()`；回放时每帧推进时间并重绘，但用调度器的 30fps 节流。
4. **y 轴取整**：`niceStep`（1/2/2.5/5/10 × 10ⁿ），避免 `92.9` 这类假精度；位数按传感器 `digits`（温度 1、压力 2、转速 0）。
5. **优先复用**：`design/chartTheme.js` 的语义色（accent/cyan/success/warning/danger）与 tooltip 样式；`components/common/AppEmpty.vue` 做空态；`SentinelNotice` 做错误提示。
6. **样式**：`<style scoped>`，颜色全走 `--ds-*` / `--smart-*`，不新增全局类；半径 `var(--ds-radius-md)`；零 `backdrop-filter`、零粒子。
7. **可访问性**：图表 `role="img"` + `aria-label`；工具栏 `role="toolbar"`；`aria-pressed` 表选中；键盘 ←/→/空格；对比度 ≥ 4.5。

## 6. 动效门禁

沿用项目既有门禁（参考库 §6），本页逐条落：

| 门禁 | 本页要求 |
| --- | --- |
| **G3 hover 兼容** | 入场动画 `animation-fill-mode: backwards`，不得覆盖 hover 抬升/描边 |
| **G5 四重降级** | 窄屏（≤760）/ `prefers-reduced-motion` / 运行期 degraded / 三档 `visualMode` 下：停回放、去过渡、静态单帧 |
| **G6 不伪造数据 + 防 CLS** | 无接口时显示 `—` 或 DEMO，不编造"看起来像真的"读数；图表容器固定高（460/340），骨架与终态同高 |
| **G7 不套股票红绿** | 运维语境：红=越界/故障，琥珀=预警；**不用绿色表示"上涨"** |
| **G8 大屏装饰不进日常控制台** | 本页不加极光、粒子、流星、扫光 |
| **G9 已实现不重复挂** | 神经网络脉冲已落在 `/agent/trace`，本页不重复 |

新增本页规则：

- 回放暂停 → 订阅数为 0（验收脚本断言）。
- 视野切换不做补间动画，直接重绘（避免"图表在跳舞"）。
- 数字不做 count-up（预测读数滚动会被误读成实时刷新）。

### 7.2 断言（`forecast-plane.browser.mjs`）

1. 路由可达：mock 会话后打开 `/sentinel/forecast`，`.forecast-plane` 存在。
2. 导航落位：SENTINEL 展开后，最后一项文本包含「预测面」，`to="/sentinel/forecast"`。
3. 三态：live（接口 200）/ demo（点按钮）/ offline（503）各渲染正确角标；offline 下所有数值为 `—`。
4. 视野切换：点 120s 后 `#chartAside` 含 `+120s`，越界列表条数变化（或空态文案出现）。
5. 回放：暂停后 300ms 内 `motionScheduler` 订阅数回到 0（通过 `subscriberCount()` 断言）。
6. 键盘：`←` 使游标时间偏移减少，`Space` 切换播放状态。
7. 无横向溢出：375 / 768 / 1024 / 1440 / 1920。
8. reduced-motion：默认不播放，`matchMedia` 为 reduce 时无进行中动画。
9. 演示数据声明：`DEMO` 角标存在；页脚含「虚构」字样。
10. 对比度：页头正文、卡片标题、轴标签 ≥ 4.5:1。
