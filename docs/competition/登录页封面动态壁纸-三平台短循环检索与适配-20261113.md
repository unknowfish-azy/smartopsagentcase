## 8. 工程门禁（引用关联文档，不重复展开）

上一轮已取证：`LoginView.vue` 已有 `CanvasAmbientField` 粒子星网 + 双层 CSS 星野 + `prefers-reduced-motion`；`visual/visualMode.js` 有 `balanced/lightweight/reduced-motion` 三档与 `adaptiveVisualBudget()` 自动降级；T11 基线 Lighthouse 桌面 92 / 移动 95、登录契约全绿。

因此封面动态壁纸**必须**：
