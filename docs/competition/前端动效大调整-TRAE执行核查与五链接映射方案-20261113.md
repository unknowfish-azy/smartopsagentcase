### 2.2 四条结构性差距

| # | 差距 | 表现 |
|---|---|---|
| G1 | **动效层级单一** | 只有「背景氛围层」，缺「数据层」「内容层」「交互层」；背景在动、数据不动 → 观感是"壁纸"不是"活系统" |

### 2.3 与评分的关联

传智杯六维里 **AI 交互体验 3% + 用户体验（前端交互 3%）+ 创新性（交互 7%）** 合计约 13% 直接吃「动效是否传达 AI 在思考/数据在流动」。当前"背景动、内容静"恰恰让评委看不到 AI 能力，属于**能低成本补回的分**。

## 4. 大调整设计：三层动效模型 + 统一编排层

### 4.1 目标模型

```
┌─ L3 交互层（用户触发）───────────────────────────────┐
│ hover 抬升 1px / 点击涟漪 / 路由转场 / 视口揭示 /      │
│ 刷新时数据重流动 / Cmd+K 结果 stagger                  │
├─ L2 数据层（本次重点，补 G1/G2）────────────────────┤
│ KPI 数字滚动 · 指标连增阶梯 · 状态色阶脉冲 ·          │
│ 图表入场/扫光 · AI 流式输出光标 · 列表 stagger        │
├─ L1 氛围层（TRÆ 已完成，保留不动）──────────────────┤
│ CanvasAmbientField 星网 · 极光 drift/sweep · 流星 ·   │
│ 暗度 mask · 果冻登录 · 启佑光带                       │
└──────────────────────────────────────────────────────┘
```

**核心原则**：**L1 不动、L2/L3 新增**，全部通过「类名」挂载，**零 template 结构改动、零 JS 改动**（与 TRÆ 的 ExecutionTrace 做法一致，风险最低）。

### 4.2 统一编排层 `motion-layer.css`

新增单一文件，集中定义：
- **节奏变量**：复用 `--ds-duration-*` / `--ds-ease-*`，新增 `--ml-*` 编排变量（stagger 步长、周期、位移幅度）
- **动效类族**（语义化命名，供各页按需挂）：
  - `.ml-rise` 入场抬升淡入（L3 B端设计）
  - `.ml-stagger > *` 子项错峰（40ms 步长）
  - `.ml-kpi` KPI 数字滚动 / tabular 微脉冲（L4 指标连增）
  - `.ml-trend` 趋势条扫光 + 连增阶梯（L4）
  - `.ml-stream` AI 流式光标 + 逐行揭示（L2 40亿token）
  - `.ml-live` 状态点呼吸（L1 时序流呼应）
  - `.ml-sweep` 图表/卡片扫光（L1 MLP+GRU 数据流）
  - `.ml-parallax` ≤2px 视差呼应（L5 宇宙星空）
- **零几何侵入**：所有动效只用 `opacity / filter / box-shadow / background-position / translateY≤2px`，**不修改 `transform` 于表单/按钮容器**，避免再次打断 `login-glass` 契约（历史上 `scale(1.004)` 曾致契约失败）。

### 4.3 四重降级门禁（必须全接）

| 门禁 | 选择器 | 行为 |
|---|---|---|
| 系统偏好 | `@media (prefers-reduced-motion: reduce)` | 全族 `animation:none; transition:none` |
| 运行时掉帧 | `[data-motion-degraded='true']` | 全族停用（复用 `motionScheduler.js`） |
| 视觉档位 | `[data-visual-mode='lightweight']` / `reduced-motion` | 全族停用（复用 `visualMode.js`） |
| 窄屏 | `@media (max-width: 768px)` | 只保留 `.ml-stream` / `.ml-live`，其余停用 |

**作用域隔离**：所有规则限定在 `.app-layout`（工具层）内，**显式排除 `.login-shell` / `.login-form`** —— 登录页已有独立动效体系与契约，不受影响。

### 4.4 与既有门禁的兼容

- 不改 `LoginView.vue`、不改 `global.css` 已有规则（仅追加 import）；
- 不改任何 `.vue` 的 template / script（P0 阶段）；
- 不新增依赖、不新增 JS、不新增网络请求；
- 因此 **T11 门禁（503 测试 / login-glass / login-layout 8 视口 / meteor / a11y 24 矩阵 / Lighthouse 92·95）理论上零回归**。
