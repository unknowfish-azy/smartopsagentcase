### 4.2 三态

| 状态 | 触发 | 表现 |
| --- | --- | --- |
| `loading` | 首次请求 | 骨架；切换投影不重新请求 |

## 5. 关联规则（实现要点）

```js
// deskModel.js
export function linkState(event, runsByTrace) {
  if (!event?.traceId) return { kind: 'no-trace' }
  const run = runsByTrace.get(event.traceId)
  if (!run) return { kind: 'miss', traceId: event.traceId }
  return { kind: 'linked', run }
}
```

四种文案（与 `DESIGN.md` §5 一致，不许改写）：

| kind | 文案 |
| --- | --- |
| `linked` | `已关联 RUN-5521 · 切到「运行」可看到高亮` |
| `miss` | `有 traceId（tr_xxx），但运行记录里没有命中——可能超出窗口或未被采集` |
| `no-trace` | `没有 traceId · 无法定位运行记录` |
| 反向 miss | `有 traceId，但纠察里没有命中（可能超出窗口）` |

**禁止**：按时间邻近、任务名相似、目标相同等方式补关联。

## 6. 交互与门禁

| 交互 | 规格 |
| --- | --- |
| 投影切换 | 420ms 交叉淡入 + 8px 位移；reduced-motion 直接切 |
| 时间窗 | 24h / 7d / 30d；切换后三个投影重算、选中清空、URL 更新 |
| 筛选 | 等级 / 工具 chips；「只看已关联」同时作用于事件与运行 |
| 选中 | 点/条可选中；箱不参与；选中保留全高竖带 + 右侧卡 + 抽屉 |
| 键盘 | `1/2/3` 切投影、`←/→` 移动选中、`Enter` 开抽屉、`Esc` 关并清选中 |
| 深链 | `?view=events|stats|runs&window=24h|7d|30d&id=EV-1042`；刷新可恢复 |

**门禁**（沿用项目既有）：

| 门禁 | 要求 |
| --- | --- |
| G3 | 入场动画 `fill-mode: backwards`，不覆盖 hover |
| G5 | 窄屏 / reduced-motion / degraded / 三档 visualMode 下无过渡、静态单帧 |
| G6 | 无接口时 `—` 或 DEMO，不编数；Canvas 容器固定高，防 CLS |
| G7 | 红=失败、绿=成功；不用红绿表示涨跌 |
| G8 | 不加极光/粒子/扫光/玻璃 |
| G9 | 不重复挂 `/agent/trace` 的神经网络动效 |

新增本页规则：

- 单 rAF 仅在切换动画期间运行，动画结束后必须 `cancelAnimationFrame`；
- 悬停用 `pointermove` 直接重绘，不建常驻循环；
- Canvas 上的数值不做 count-up。

### 7.2 断言（`inspector-desk.browser.mjs`）

1. `/inspector/desk` 可达；`role="tablist"` 有三个 tab，默认 `aria-selected="true"` 在「纠察」。
2. 三个投影切换：`data-view` 变化；主轴 `aria-labelledby` 文本随之变化；切换后选中不丢。
3. 时间窗 24h→7d：URL `?window=7d`，x 轴刻度数量变化。
4. 键盘：`3` 切到运行；`←/→` 改变选中 id；`Enter` 打开抽屉（`aria-expanded="true"`）；`Esc` 关闭。
5. 关联文案：造一条带 trace 的事件 + 一条同 trace 的运行 → 显示「已关联」；再造一条无 trace → 显示「没有 traceId」；再造一条有 trace 但无运行 → 显示「没有命中」。**断言三种文案都在不同 fixture 下出现。**
6. 空态：events 返回 `[]` → 显示「窗口内没有纠察事件」，不是空白画布。
7. 部分失败：runs 接口 503 → 运行投影显示 `—` + 原因，纠察投影仍正常。
8. DEMO：点「查看演示数据」→ `DEMO` 角标存在，页脚含「虚构」。
9. 无横向溢出：375 / 768 / 1024 / 1440 / 1920。
10. 屏幕阅读器列表：`sr-only` 列表项数 = 当前投影可见项数。
11. 单测：`Preview:` 不出现在 `InspectorCenterView.vue`；分箱函数对空数组返回空箱；`linkState` 四态正确。
