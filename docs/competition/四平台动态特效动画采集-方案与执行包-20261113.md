## 0. 结论速览 + 授权边界判定（先行）

### 0.1 一句话

**可以爬，但要先锁定「爬什么」**：四平台（抖音 / B站 / 小红书 / YouTube）上真正对本作品有用、且能安全落进竞赛作品的，不是视频文件本身，而是**公开可发现的内容元数据 + 可复现的动效手法拆解**。产物是一份可直接交实现模型照做的 md 动效参考库。

### 0.2 边界表

| 判定项 | 结论 |
|---|---|
| ✅ 边界内 | 四平台**公开内容发现**：标题 / 创作者 / 规范链接 / 时长 / 封面缩略图（仅研究用途）/ 简介与专栏正文 / 公开字幕或二手拆解文章；据此做**动效语义拆解**并映射到本项目 `ml-*` 类与页面。 |
| ⚠️ 不推荐 | 批量高频请求、绕过签名与风控、使用未授权的登录态凭证、抓取用户数据。 |
| ❌ 越界 | 下载 / 搬运创作者视频或动图进仓库、进竞赛作品、进答辩录屏。版权归创作者与平台；本作品**公开展示 + 仓库开源 + 评审录屏**构成传播行为，不是个人桌面使用。 |
| 处理原则 | 沿用项目既有「占位符方法论」：保留「平台灵感位」结构，落地素材改从自制 / 授权 / 可商用库取（见 §6）。 |

### 0.3 为什么不是「下载视频」

项目内已有三份文档做过实证裁决，本方案不重复论证、直接继承：

1. 抖音短链 `v.douyin.com/xN1ozBw-5Go/`、`v.douyin.com/P_Rv51tXaWw/` 经回源均返回「抱歉出错了 / 请尝试在抖音内观看」——**Web 端拿不到画面内容**（来源：`前端动效大调整` §3.1）。
2. 小红书具体笔记直链 Web 端反爬强，通常拿不到 / 易失效，只能给搜索页与关键词（来源：`登录页封面动态壁纸` §4）。
3. B站 BV 页、专栏 opus、在线 demo 可打开；**视频流需 WBI 签名 + 登录 Cookie**。
4. YouTube 为本次新增平台，有无需 API key 的 oEmbed 与公开 watch 页元数据；**视频流下载受 ToS 限制，且国内网络可达性未实测**（§2 要求先做探针）。

> 所以「爬取」在本方案中的准确定义是：**结构化采集公开参考案例 + 动效手法拆解，产出 md 参考库**。若你实际想要的是可落地的动效素材文件，走 §6 三条路径，不要从四平台搬。

## 3. 动效分类法 E1–E8（对齐项目禁用项）

| 类别 | 名称 | 典型手法 | 本项目对应 | 门禁提示 |
|---|---|---|---|---|
| E1 | 氛围 / 粒子星野 | 粒子网络、极光漂移、流星、视差景深 | L1 已有（启佑五层） | **只补灵感，不新增层**；控制台禁 blur |
| E2 | 光带 / 扫光 / 描边流光 | `background-position` 光带、渐变边框流、脉冲环 | `ml-sweep` / `ms-*` 强效果档 | 不用 `outline` / `box-shadow` 做卡片动效（会吃焦点框与 hover） |
| E3 | 数字 / KPI 过渡 | 数字滚动、tabular-nums 脉冲、连增阶梯、sparkline | `ml-kpi` / `ml-trend` / S-KPI | 不伪造数据；不抖动、不 CLS |
| E4 | AI 流式 / 思考态 | 逐 token 光标、逐行揭示、打字机、进度累积 | `ml-stream` / `ml-stream-lines` / S-AI | 不阻塞首屏；reduced-motion 直接出终态 |
| E5 | 卡片 / 列表编排 | stagger 入场、骨架→内容、hover 1px 抬升、路由转场 | `ml-rise` / `ml-stagger` / S-B | 入场动画终态 `transform` 会覆盖 hover 抬升（项目已踩坑） |
| E6 | 图表动效 | 折线生长、柱状入场、扫描高亮、节点扩散 | `.ops-chart` / `ExecutionTrace` 已有 | 禁彩虹 donut；状态色统一 |
| E7 | 转场 / SVG 路径 | morph、路径描边、clip 揭示、视口揭示 | `ml-reveal-on-scroll`（渐进增强） | 渐进增强仅 `@supports (animation-timeline: view())` |
| E8 | 3D / WebGL / Shader | Three.js、GLSL 粒子、品牌 mark | **仅登录 / 首页品牌层**（D2 裁决） | 控制台不引入；`rAF ≤ 3`、首屏无长任务 |

## 6. 合规红线与三条落地路径

**红线（继承既有裁决，不重新讨论）**
1. 四平台创作者内容仅作风格 / 手法参考，不下载、不搬运、不进仓库、不入竞赛作品。
2. 不绕过签名 / 风控、不批量高频请求、不抓用户数据、不使用未授权登录态凭证。
3. 竞赛作品公开展示 + 仓库开源 + 答辩录屏 = 传播行为，需可溯源证据链（合规台账即为此设）。
4. 本阶段及第二阶段均**不改前端代码、不跑 build、不动任何已验收契约**。

**若你确实需要「可落地的动效素材」**（沿用 `登录页封面动态壁纸` §7）：

| 路径 | 做法 | 授权 | 推荐度 |
|---|---|---|---|
| **A 自制（省赛 5 天首选）** | 把四平台拆解出的手法用项目已有 `ml-*` 类族 / 纯 CSS / Canvas 复现 | 完全自有 | ★★★★★ |
| **B 书面授权** | 联系创作者 / 站方取商用许可，截图存档 | 待确认 | ★★★ |
| **C 可商用库** | 按拆解出的风格词去 Pexels / Pixabay / Coverr 找同款 | 已有 License | ★★★★ |

> 明确不建议：把 B站 / 抖音 / 小红书 / YouTube 的视频或动图直接搬进竞赛作品。
