## 0. 三层体系（先看这个）

| 层 | 文件 | 何时生效 | 强度 |
|---|---|---|---|
| L1 氛围层 | 各页 `CanvasAmbientField` / 极光 / 流星 / 果冻 | TRÆ 已落地，保留不动 | 中 |
| L2/L3 克制基线 | `assets/styles/motion-layer.css` | 所有工具层页面（`balanced` / `lightweight` 均生效，但轻量档停动画） | 低 |
| **强效果档** | `assets/styles/motion-strong.css` | **仅 `visualMode === 'balanced'`** | **高** |

**一句话**：想"猛"就把视觉模式切到「平衡视觉」；切「轻量视觉 / 减少动态」或系统开了 reduced-motion，强效果层**整层不加载**。

## 2. 克制基线语义类（`ml-*`，需手动挂到具体元素）

| 类名 | 效果 | 建议挂载位置 |
|---|---|---|
| `ml-rise` | 入场抬升淡入（带 translateY 2px） | 手动挂载的卡片 / 面板 |
| `ml-stagger` | 子项错峰入场（前 12 项，40ms 步进） | KPI 网格、指标卡列表容器 |
| `ml-kpi` | 读数低频呼吸 | 自定义 KPI 数字（已有 `.ops-kpi__value` 自动挂载） |
| `ml-trend` | 三段连增阶梯光条（需 3 个 `<i>` 子元素） | 指标卡右下角 |
| `ml-stream` | AI 流式光标（`::after`） | AI 输出文本容器 |
| `ml-stream-lines` | 逐行揭示（前 6 行，90ms 步进） | 思考过程 / 简报段落容器 |
| `ml-live` / `--warn` / `--critical` | 状态点呼吸（绿/橙/红） | 健康状态徽标 |
| `ml-sweep` | 卡片扫光（`::after`） | 重点数据卡 |
| `ml-flow` | 竖向数据流（`::before` 需自备竖线） | 步骤链连接线 |
| `ml-parallax` | 极轻微视差（background-position） | 大面积装饰层 |
| `ml-reveal-on-scroll` | 视口揭示（**渐进增强**，仅支持 `animation-timeline: view()` 的浏览器） | 长页面分段卡片；**不要挂到已有 `ml-fade-in` 的元素上**，会抢时间轴 |

## 4. 门禁速查（改任何动效前必读）

| 条件 | 行为 |
|---|---|
| `visualMode = lightweight / reduced-motion` | 强效果层整层不生效；基线层动画停用 |
| `prefers-reduced-motion: reduce` | 全部 `animation/transition` 归零 |
| `[data-motion-degraded='true']`（`motionScheduler.js` 掉帧置位） | 全部停用 |
| `max-width: 768px` | 强效果层停用；基线仅保留 `.ml-stream` / `.ml-live` |

### 四条硬红线（历史上踩过坑）

1. **不给 `.login-form` 加 transform** —— `login-glass` 契约要求恒为 `none`（曾因 `scale(1.004)` 挂掉）。
2. **不给 `.login-stars-front` 加 transform** —— `login-layout` 契约校验它必须留在 `.login-organisms` 舞台内。
3. **不用 `outline` / `box-shadow` / `border-color` 做卡片动效** —— 会分别吃掉 `:focus-visible` 焦点框、覆盖 `:hover` 抬升/阴影；用 `background-image` 光带最安全。
4. **全局 CSS 不要引用组件 scoped 的 `@keyframes`** —— Vue 会给 keyframes 加 hash 后缀（如 `login-stars-twinkle-7ba5bd90`），全局引用不到；强效果层自带 `ms-*` keyframes 就是这个原因。

> 另外：降级规则里**不要写通配 `transform: none !important`** —— Element Plus 的 popper / 下拉层用 `translate3d` 定位，会被打错位。
