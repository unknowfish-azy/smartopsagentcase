# 启佑 Spark You · 智慧星空 · 前端动效统一规范

> 版本：v1.0 · 日期：2026-11-13 · 适用页面：7 页（登录页 · 执行轨迹 · 守护Agent · 告警中心 · 工单中心 · 守护总览 · Agent控制中心）

---

## 1. 设计理念

**目标风格**：启佑 Spark You 智慧星空视频（BV1HZ9YBcEnY）+ 2023 国一智慧课堂数据可视化平台（BV17u4y1Q7o7）。

**核心视觉**：
- 深蓝深空底 `#040B16`
- 青绿星云 `#3FB950 / #7AD7F5`
- 粒子网络 + 双层极光漂移 + 流星划过
- 玻璃卡（blur + 青绿高光描边）

**非目标**（严格排除）：
- 不引入视频背景（Vite 首屏体积 2MB+，T11 性能基线不允许）
- 不新增具体物象（鲸鱼 / 果冻 / 几何人——保持抽象星野）
- 不牺牲 reduced-motion（所有动画必须可关断）

## 3. 组件层动效规格

### 3.1 CanvasAmbientField（粒子网络）

| 参数 | 标杆值 | 范围 | 说明 |
|---|---|---|---|
| `starMultiplier` | **1.8** | 1.0–2.0 | 基准 130 颗 × multiplier。登录页/守护页 1.8 → 234 颗 |
| `connectParticles` | **true** | boolean | 粒子间距离内自动连线 |
| `connectMaxDist` | **130px** | 80–160px | 连线最大距离。越小网越稀，越大越密 |
| opacity | **0.48** | 0.35–0.55 | 背景层整体透明度 |
| fluid drift | ✅ 内置 | — | 每帧 perlin noise 偏移，零代码量 |

**体积**：~1KB JS（无额外资源文件）

### 3.2 启佑-aurora（双层极光）

| 属性 | 值 | 说明 |
|---|---|---|
| 主光带 | 2 层 radial-gradient（青/绿各一） | `rgba(122,215,245,.22)` + `rgba(63,185,80,.16)` |
| sweep 扫光球 | `::after` 伪元素 | `rgba(122,215,245,.35)` + `blur(18px)` |
| filter blur | **24px**（主）/ **18px**（扫光） | 越大越柔和 |
| background-size | **240% × 240%** | 为 drift 留足够空间 |
| drift 周期 | **22s ease-in-out** | 双向 alternate 缓动 |
| sweep 周期 | **32s ease-in-out** | 往返扫过 |
| 亮色模式覆盖 | 深青/深绿降饱和 | `.启佑-shell[data-theme='light'] .启佑-aurora` |
| reduced-motion | `animation: none` | CSS 媒体查询关断 |

**体积**：0 KB（纯 CSS）

### 3.3 MeteorShower（流星）

| 属性 | 值 |
|---|---|
| 数量 | 6 颗 CSS 流星 |
| 触发 | 异步随机（9–14s 间隔） |
| 依赖 | `MeteorShower.vue` 组件 |
| 移动端 | `v-if="!isMobile"` 不加载 |
| reduced-motion | 组件内部关断 |

### 3.4 启佑-mask（暗度遮罩）

| 属性 | 深色 | 浅色 |
|---|---|---|
| 中心 | transparent | transparent |
| 边缘 | `rgba(4,11,22,.42)` | `rgba(234,243,250,.42)` |
| 范围 | radial-gradient 40%→100% | 同 |

**作用**：压暗背景边缘，提升表单/卡片对比度。

## 5. 工程门禁（不可绕过）

### 5.1 三档视觉预算

| 档 | 触发条件 | CanvasAmbientField | 极光 drift | 极光 sweep | MeteorShower |
|---|---|---|---|---|---|
| **balanced** | 默认（桌面 + 非 reduced-motion） | ✅ 全速 | ✅ 22s | ✅ 32s | ✅ 6 颗 |
| **lightweight** | （保留接口，暂未全链路触发） | ✅ 无连线 | ⚠️ 32s 慢速 | ❌ | ❌ |
| **reduced-motion** | `@media (prefers-reduced-motion: reduce)` | ❌ 静态帧 | ❌ | ❌ | ❌ |

### 5.2 移动端 <1024

```js
const isMobile = ref(window.innerWidth < 1024)
function updateMobile() { isMobile.value = window.innerWidth < 1024 }
onMounted(() => { updateMobile(); window.addEventListener('resize', updateMobile) })
onBeforeUnmount(() => window.removeEventListener('resize', updateMobile))
```

所有动效元素加 `v-if="!isMobile"`。移动端只保留 mask（保证对比度）+ 业务内容。

### 5.3 主题切换

```vue
<div class="启佑-shell" :data-theme="resolvedTheme">
```

| 主题 | 背景色 | 极光色 | mask |
|---|---|---|---|
| `dark` | `#040B16` 深空 | `rgba(122,215,245,.22)` 青绿 | `rgba(4,11,22,.42)` |
| `light` | `#EAF3FA` 浅蓝星天 | `rgba(26,110,154,.14)` 深青降饱和 | `rgba(234,243,250,.42)` |
| 跟随系统 | 自动 | 自动 | 自动 |

### 5.4 reduced-motion

所有 CSS 动画必须加：
```css
@media (prefers-reduced-motion: reduce) { .启佑-aurora, .启佑-aurora::after { animation: none; } }
```
