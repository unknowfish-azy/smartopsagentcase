## 2 门禁接线

- 纯 SVG + CSS `stroke-dashoffset` 流动；**无 canvas、无 three.js、无 `backdrop-filter` / filter blur**；不新增依赖。
- 四重降级全部接上：
  - `@media (prefers-reduced-motion: reduce)` → 动画停、虚线变实线（保留静态连线与文字）
  - `[data-motion-degraded='true']` → 动画停
  - `.app-layout[data-visual-mode='lightweight' | 'reduced-motion']` → 动画停
  - `@media (max-width: 768px)` → 缩窄并允许容器内横向滚动，**不撑大 `documentElement.scrollWidth`**
- 降级只停运动、不隐藏信息；端点文字与工具名始终可读。
- 交互沿用现有 tab：选中点亮、再点取消、切换目标重新点亮；无新增点击语义。

## 5 强效果渲染升级（15:56 用户「强特效渲染继续做哦」）

> 沿用 `motion-strong.css` 的既定规矩：**强效果只在 `visualMode === 'balanced'` 生效**，其余档与降级条件自动退静态；不新增依赖、不引入 canvas/three.js/blur。

| 层 | 效果 | 数据绑定 | 降级行为 |
|---|---|---|---|
| 中心能量核 | 扫描弧 5s 匀速旋转 + 光晕 2.8s 呼吸 | 仅命中管线时运行（`rewb-radia--live`），无事件静默 | 非 balanced / reduced-motion / degraded / 窄屏 → `opacity:0; animation:none` |
| 路径流光点 | 10px 短 dash 沿贝塞尔路径传导，1.9s 循环 | 5 条命中流线按**真实 pipeline 顺序**错峰 80ms（`--ray-order`） | 同上 |
| 端点扩散环 | 4px→12.8px 扩散，`transform-box: fill-box` 保证以圆心缩放 | 同管线顺序错峰，未命中不渲染动画 | 同上 |

**关键实现点**：
- 组件新增 `activeOrder` prop，宿主传 `activeTarget.pipeline`（真实工具 id 数组）；`orderMap` 用 Map 取 index，未命中工具回退到卡片序号，保证顺序可解释、不随机。
- 流光点用 `stroke-dasharray: 10 1000` + `stroke-dashoffset` 动画（等效单光点跑完全程），避免 `<animateMotion>` 在减弱动态下无法用 CSS 关停的问题。
- 扩散环用 `transform-box: fill-box; transform-origin: center`，否则 SVG circle 会以 viewBox 原点缩放而飞出画布。
- 强效果层选择器全部带 `.app-layout[data-visual-mode='balanced']`，与 `motion-strong.css` 同构；降级规则对四重条件逐一显式覆盖，含 `::before/::after` 同类风险点。

**门禁复跑**：typecheck 0、lint 0 error / 4 既有 warning、`npm test` **812/812**、用户层 build ✅、admin build ✅；浏览器实测在原有 8 项基础上新增 4 项断言全过——balanced 下 `rewb-core-spin` / `rewb-ray-spark` / `rewb-ray-pulse` 三个动画名命中、5 条命中流线的 `animationDelay` 为 5 个不同值（真实管线顺序）、lightweight 档强效果层 `opacity === 0`、系统 reduced-motion 下基线流线动画停用。

## 6 a11y 矩阵补测与两处真实修复（16:14 续）

新增 SVG + 强效果后补跑 5 组视口×主题（1440 dark/light、768 dark、375 dark/light）的 axe WCAG A/AA 扫描，抓到两处**真实**缺口（非动画过渡帧假阳性）：

| 问题 | 位置 | 根因 | 修法 |
|---|---|---|---|
| `color-contrast` serious ×50 | 选中目标后未命中的工具卡片 | `.rewb-card--dim { opacity: .45 }` 把标题和仓库链接一起压到 4.5:1 以下 | 改为**虚线边框 + 透明背景**弱化，不再动文字透明度；弱化的是「是否属于当前管线」这一线索，不是可读性 |
| `scrollable-region-focusable` serious ×1 | 辐射图横向滚动容器 | `.rewb-radia__scroll` 有 `overflow-x:auto` 但键盘无法聚焦 | 加 `role="region"` + `aria-label="REA 工具辐射图（可横向滚动）"` + `tabindex="0"` |

**复跑结果**：a11y 矩阵 5/5 PASS（serious/critical 0、横向溢出 0）、typecheck 0、lint 0 error / 4 既有 warning、功能浏览器脚本 ALL PASS、`npm test` **816/816**（测试数较本轮开局 812 增加 4 条，来自并行工作）。

> 验收口径：a11y 扫描选中目标后、等有限次入场动画结束再跑 axe，避免把过渡帧半透明误判为对比度不足；`iterations: Infinity` 的呼吸/脉冲不等待，不会挂住。
