## ⑤ 口径陷阱（4 个）

- **119 表** = 迁移脚本离线定义去重数，不说"运行库实测"。
- **首个 SSE 事件 16.6ms** = 框架 run 事件，**禁当时延成绩**；真实时延用首 token 3590ms。
- **M04 3/3 高危低估** = 双轨不一致（审批链读 manifest），**不等于已越权执行**。
- **恢复契约** = 保守口径：弱基线 21 次假恢复、实现假恢复 0、一致 41/42（见 claim-matrix #6）；4 分钟稿的 42:42 需统一。
