# 前端企业级彻底重构方案（2026-11-13）

> 定位：本文件是「前端重构规划」，只出方案、不落地。交由实现模型按 §6 工作包执行。
> 背景：T11（简约/去 WebGL/扁平化）已达标工程与性能，但视觉偏**平、硬、缺乏层次与生命感**，被判定"太僵硬"。本方案在保留 T11 工程成果（tokens / a11y / 性能 / 控制台 blur=0）前提下，把视觉语言从"扁平"升级为"分层企业级"。
> 关联：本方案取代 T11 的"纯扁平"方向；D1（首页 Bento）在此**裁决变更为采纳**；D2 品牌 WebGL 仅留登录/首页品牌层，控制台不引入 blur。

---

## 0. 问题诊断：为什么"太僵硬"

| 症状 | 根因 |
|---|---|
| 所有卡片同一平面、无前后之分 | 扁平化过度，缺少 Z 轴层次 |
| 字号/字重几乎一致 | 无排版层级（type scale），标题与正文同权 |
| 切换/悬停无反馈 | 缺少微交互，页面"静默" |
| 信息密度一刀切 | 无密度模式，既不紧凑也不舒展 |
| 首屏像品牌宣传而非工作台 | 首页是 HomeOrbitCarousel 轮播，不是运维仪表盘 |

**结论**：用户要的"企业风格" ≠ "更平"，而是**有秩序的力量感**——层次、深度、信息层级、克制的生命感。

## 1. 设计目标与原则（重新定义"企业级"）

- **品类定位**：Enterprise Observability Console（企业级可观测/运维控制台），对标 Datadog / Grafana / LangSmith / Supabase，而非营销型后台。这恰好契合 SmartOpsAgent 的 AI 运维属性。
- **四原则**：
  1. **层次优先于扁平**：用 surface 明度步进 + 1px hairline + 极柔阴影建立 Z 轴（不用 blur）。
  2. **密度可调**：提供 Compact / Default 两档密度，紧凑而不局促（借鉴 Semi Design）。
  3. **动效克制有反馈**：统一 150ms micro-feedback、骨架屏、hover 预览，不整页重渲、不堆光效。
  4. **深色优先 + 单一 accent**：暗色为第一设计面，accent 恒 #2496ED，语义色按暗色对比度校准。
- **兼容既有约束**：保留 T11 的令牌、a11y 矩阵、Lighthouse、503 测试、双端构建、控制台 blur=0；只改视觉语言，不动工程基线。

## 3. 新设计语言（核心：把"平"变"层"）

### 3.1 色彩与表面系统（治愈僵硬的主药）
- **真灰底，非纯黑**：base ≈ `#0E1116`–`#14181F` 区间真灰（避免纯黑 halation/眼疲劳，Linear 范式）。
- **三层表面明度步进**（替代全扁平同色）：
  - `--surface-base`（页面底）`#0E1116`
  - `--surface-raised`（卡片）`#151A21`（+1 档明度）
  - `--surface-overlay`（弹层/抽屉）`#1B212A`（+2 档明度）
- **分层抬升**：卡片 = `--surface-raised` + `1px hairline border (rgba(255,255,255,.06))` + 极柔阴影 `0 1px 2px / 0 4px 16px rgba(0,0,0,.35)`。**不靠 blur**（保持 T11 G3 控制台 blur=0）。
- **单一 accent**：`#2496ED` 在去饱和系统中为唯一焦点色；语义色（成功/警告/危险/信息）按暗色对比度校准（Stripe 范式）。

### 3.2 排版层级（9 级字阶 + 字重对比）
- 建立 `display / h1 / h2 / section / body / caption / overline` 层级；数字用 `font-variant-numeric: tabular-nums`；关键指标大字号 + 薄字重（Stripe/Light 范式），告别"全一样重"。

### 3.3 布局系统（Bento + 12 栅格 + 256px 侧栏）
- 侧栏 256px（收起 64px，保留图标 + aria-label）；主区 12 列栅格、24px gutter、行 `minmax(180px, auto)`。
- 首屏 4–6 KPI 带（D1 裁决变更为**采纳 Bento 首页**），替代当前品牌轮播。

### 3.4 微交互与生命感（克制）
- 统一 `150ms` 过渡曲线；hover 预览下钻；骨架屏匹配内容形状；**Cmd+K 命令面板升级**（已有 CommandPalette.vue，强化）；数值变化过渡（不整页重渲）；保留 `prefers-reduced-motion` 降级。

### 3.5 AI 原生（SmartOpsAgent 差异化）
- 仪表盘头部**情境简报层**：用自然语言总结"自上次会话以来最关键的变化"（Agent 巡检结论 / 异常 / 风险）。这是 2026 AI-native dashboard 趋势，且正是本项目 Agent 能力的天然载体（把"AI 交互体验 3%"做成招牌而非点缀）。

| 页面 | 现状 | 重构动作 |
|---|---|---|

| 首页/仪表盘 | HomeOrbitCarousel 品牌轮播 | **Bento 重构**：KPI 带 + 态势总览 + 活动流 + Agent 情境简报（D1 采纳） |

| AI 对话/Chat | 已 E2E 验证真实 AI 对话 | 强化流式渲染 + 思考态可视化 + 错误边界（招牌体验） |

## 5. 验收门禁（升级 T11 §4.1）

**新增（本方案专属）：**
- 真灰底三档 surface，无纯黑；分层抬升无 blur。
- 9 级字阶可用，关键指标 tabular-nums。
- Bento 首页（KPI 带 + 态势 + 活动 + 简报）。
- 微交互 150ms 统一；Cmd+K 可用；骨架屏匹配形状。
- AI 情境简报层组件存在且渲染 Agent 摘要。

**保留（T11 工程基线）：**
- 单一 accent #2496ED、无渐变按钮、无彩虹 donut、无装饰大写侧栏、无开场问候（登录语境除外）。
- a11y 24 矩阵 0 严重；Lighthouse 桌面/移动 ≥ 90；503 测试 0 fail；双端构建通过。
- **性能红线**：不新增控制台 `backdrop-filter` blur（T11 G3）；rAF ≤ 3；首屏无长任务。

**回滚**：每次工作包独立 commit + git tag，破坏 T11 契约（login-glass/layout/meteor）即回退。

## 8. 一句话总结
**"僵硬"源于扁平与无层次。重构方向 = 真灰底 + 三层表面明度步进 + 极柔阴影（建立 Z 轴，不用 blur）+ 9 级字阶 + Bento 首页 + 150ms 克制微交互 + AI 情境简报层；保留 T11 全部工程与性能成果。参考以 Soybean/Vben/Arco Pro（GitHub）与 Semi/Arco（抖音字节同源）为锚，对标 Datadog/Grafana/LangSmith 的企业级可观测控制台气质。**
