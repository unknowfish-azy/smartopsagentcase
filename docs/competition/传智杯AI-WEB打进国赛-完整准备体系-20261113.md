## 0. 三个必须先讲清的事实（决定全部策略）

### 0.1 赛道真相
你报的是**传智杯 AI WEB 网页开发挑战赛**，评分标准以赛氪官方页（saikr.com/vse/2026AIWEBKF）公布的「六维权重」为准，**不是**互联网+/睿抗/AIC。两者评分维度完全不同，之前按其他赛事推导的方案全部作废。

### 0.2 时间炸弹（最致命）
- 今天 **2026-11-13**。
- **省赛作品提交截止：2026-11-18** → 仅剩 **5 天**。
- 赛制：初赛（院校选拔）→ 省赛（复赛，作品题）→ 国赛（决赛，2026 年 12 月）。
- **晋级规则：省赛一/二/三等奖获得者晋级决赛（国赛）。**
- 国赛新增 **现场答辩，占决赛总分 30%**；省赛评审意见预计 2027 年 1 月底发布。
- 结论：「打进国赛」的第一步是 **5 天内把省赛材料做齐做扎实、确保拿省一/省二**。

### 0.3 评分结构真相（决定资源分配）
官方六维权重：

| 维度 | 权重 | 与本项目关系 |
|---|---|---|
| **AI 技术深度** | **35%（最高）** | LLM8 + Agent8 + RAG6 + 多模态5 + 安全4 + MCP4 |
| **创新性** | **25%** | 选题10 + 技术方案8 + 交互7 |

| 社会价值与商业潜力 | 10% | 社会5 + 商业5 |

**关键认知（请务必接受）：**
- 纯「**UI 视觉**」只占 **4%**，不是夺分点。前端总盘子 = 工程质量 10% + 用户体验 10% = **20%**，其中 6% 是交互、只有 4% 是视觉。
- **真正决定名次的是 AI 技术深度 35% + 创新性 25% = 60%**。而 SmartOpsAgent 的强项恰好在这里（Agent / RAG / 审批安全），这才是能打名次的「夺分线」。
- 但前端是**「体验线 + 门面 + AI 能力呈现载体」**：① 20% 这块要稳拿（不能丢分）；②「AI 交互体验 3%」完全由前端承载（流式输出、思考态、错误边界）；③ 首屏印象影响评委对所有维度的观感。
- 所以「前端设计打进国赛」的正确拆解 = **前端做到国赛级（已接近完成）+ 用前端把 AI 能力漂亮地呈现出来（AI 交互体验 3%）**。
