# 科研助手使用指南

> 面向「科研助手」（菜单 **SCHOLAR / 科研助手**，含四个页面）的使用者文档。
> 该功能组把 `knowledge/reference/ops-knowledge-rag` 语料库的蒸馏快照变成四件研究工具：
> 引用溯源问答、研究资料卡、综述生成器、检索编排流水线。
>
> 定位：**离线语料的研究工作台**，不是 AI 问答机——所有页面都是对蒸馏快照
> `atlasDistilled.json` 的确定性计算，没有大模型参与，检索不到就如实返回空。

## 一、四个页面总览

| 页面 | 路由 | 一句话定位 |
| --- | --- | --- |
| 引用溯源问答 | `/scholar/qa` | 提问 → 命中文档 → 每条证据带 [n] 编号与语料路径 |
| 研究资料卡 | `/scholar/cards` | 章节蒸馏成翻转背诵卡，正面主题、背面原文节选 |
| 综述生成器 | `/scholar/review` | 圈定文档 → 组装带引用编号的综述 → 导出 markdown |
| 检索编排 | `/scholar/pipeline` | 一次检索拆成五段可见流水线，展示真实中间产物 |

四个页面共用同一份数据与同一个引擎：

```
knowledge/reference/ops-knowledge-rag/     ← 语料库（只读）
scripts/atlas/distill-atlas.mjs            ← 蒸馏器（npm run atlas:distill）
frontend/src/views/atlas/atlasDistilled.json ← 蒸馏快照（四页面唯一数据源）
frontend/src/domain/scholar/scholarEngine.js ← 检索/组卡/综述/流水线引擎
```

## 二、引用溯源问答（/scholar/qa）

1. 输入自然语言问题（如「GPU 性能优化」），可选课程范围，点「检索」；
2. 问题被拆解为检索词（英文单词 + 中文双字组，停用词自动丢弃）；
3. 命中文档按相关度排序展示：标题、相关度分值、命中的章节引用块（原文节选）、命中词；
4. **检索不到时返回「没有命中」**——这是诚实结果，本页不会在没有证据时编造回答。

打分规则：标题命中权重最高（×8），章节标题次之（×4），关键词表与正文节选再次；
分值乘以 IDF 稀有度权重——越少见的词命中，得分越高，压制「存在」「主题」这类常见词的误命中。

> 📷 **截图占位**：`docs/images/scholar/qa-empty.png`（待补）
> 内容：检索乱码（如 `qqzzxxwwvv`）后的「没有命中」诚实空态。

## 三、研究资料卡（/scholar/cards）

- 快照里每篇文档的**章节**（带正文节选的，每篇最多 12 节）蒸馏成一张卡：
  **正面** = 章节标题 + 出处文档名；**背面** = 该节正文节选（≤160 字）+ 语料路径 + 相关命令；
- 点击卡片翻转；「上一张 / 下一张」翻页，顶部显示进度与翻卡次数；
- 卡序按快照文档顺序排列（确定性组卷，无随机），刷新不变，方便对照复习；
- 系统开启「减弱动态效果」时，翻牌退化为直接切换（无过渡动画）。

## 四、综述生成器（/scholar/review）

两步操作：

1. **圈定范围**：左侧按课程/标题筛选文档，勾选 1-20 篇（「全选可见」一键勾前 20 篇）；
2. **生成**：右侧输入综述标题，点「组装综述」。

产出结构：

| 部分 | 内容 |
| --- | --- |
| 概览 | 文档数、字符量、章节数、代码块数 |
| 主题脉络 | 每篇文档 [n]：前 4 个标题 + 前 2 段正文节选 |
| 高频命令 | 选中文档聚合的命令 Top10（`docker ×100` 这种形式） |
| 引用表 | [n] → 标题 + 语料路径 + 所属课程 |

「复制 markdown」与「下载 .md」导出的文件**页首自带诚实声明**（结构化组装、非大模型生成），
引用表含真实路径，拿到语料库即可回查。

## 五、检索编排流水线（/scholar/pipeline）

输入一个检索任务，五段流水线依次点亮：

```
① PARSE     解析问题     → 检索词 chips（停用词已剔除）
② RETRIEVE  全库检索     → 扫描篇数 + 候选文档及原始分
③ FILTER    相关性筛选   → 保留篇数与阈值说明
④ SUMMARIZE 证据汇总     → Top 3 引用块（标题 + 节选）
⑤ PRODUCE   引用产出     → 结论陈述 + 跳转「引用溯源问答」深链
```

每一段展示的都是引擎真实中间产物——没有隐藏步骤，也没有装饰性动画数据。
阶段推进只是展示节奏（320ms/段），计算在点击瞬间一次完成；
「减弱动态效果」开启时五段同时呈现。任务无命中时，⑤ 段如实说明
「没有命中，不编造答案」。

> 内容：执行「docker 镜像分层原理」后的五段流水线全景（左侧节点轨道 + 每段数据卡）。

## 六、与知识蒸馏图谱的关系

- **图谱（/atlas）** 回答「语料库里有什么」——课程、文档、命令的鸟瞰；
- **科研助手（/scholar）** 回答「怎么用这些语料做研究」——检索、背诵、综述、过程展示；
- 语料更新后两处数据同源：执行 `npm run atlas:distill` 重新蒸馏，
  快照里的 `sections`（章节节选）与 `terms`（关键词）字段就是为科研助手准备的证据层。

## 七、诚实边界（本功能组的设计承诺)

1. **没有大模型**：所有结果都是对快照的确定性检索与结构化组装，页面均如实声明；
2. **引用可回查**：每条证据都带语料库真实路径，拿到文件即可验证；
3. **空即是空**：检索不到时返回诚实空态，不凑答案；
4. **只读蒸馏**：蒸馏器只读语料文件、不执行其中的命令；页面不把快照冒充实时数据。
