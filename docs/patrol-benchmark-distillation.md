## 二、分项说明

### 1. 多设备统一接入 —— 已完整蒸馏 ✅

这是当初从智巡孪卫**明确只蒸馏的一小块**，已闭环：

- **后端唯一来源**：`RobotTeleopProfiles` 维护 `CAR/DOG/SPIDER/ROBOT` 的轴、限速、步态、运动学。
- **能力清单驱动 UI**：前端不按 `formFactor` 分支，只读统一 profile 渲染摇杆（差速车 = 前进+转向，四足/全向 = 横移+转向）。
- **台账**：`RobotRegistryService` 登记/读取 `robot_device`，解析 capabilities/transport 并下发 `teleop` 字段。
- **人形**：占位只读，未纳入本轮 `enabled` 范围。

### 2. 三维数字孪生 —— 已有，但非「多设备孪生」 ✅（范围差异）

智维Agent 有 3D 孪生，但对象是**云服务器厂房**（`DataCenterTwinView`），不是智巡孪卫那种「机器人本体孪生 + 校园/园区场景」。机器人巡逻轨迹已叠加进 3D 场景，属于「场景孪生 + 机器人轨迹」，与参考项目的「设备级数字孪生」定位不同。

### 3. 实时视频回传 —— 部分 ◐

有 `RobotVideoPanel` 视觉回传面板，但传输仍走 simulated（真机 BLE 帧格式未抓包），非实时视频流。参考项目的「实时视频」是真机摄像头流，这块智维Agent 尚未对齐。

### 4. 多模型视觉预警 —— 已有 ✅

`VisionInspectionService` 支持视觉模型分析图片并把结论落为纠察事件（`status=REVIEW`、人工复核），支持普通来源与机器人抽帧（`CAPTURE` 触发）。模型未配置时明确报错不伪造结果。

### 5. 平台助手 —— 已有 ✅

对话 Agent（chat）+ 机器人插件工具（机队状态、任务提交、路线生成、语音指令等），走 Java 后端 `/api/robot/fleet/*`。

### 6. 日志诊断 —— 已有 ✅

日志诊断页面已上线（侧栏 OPERATIONS 组），属平台运维能力。

## 三、缺口与可借鉴点

| 缺口 | 说明 | 优先级 |
|---|---|---|
| 设备级数字孪生 | 智维Agent 是「厂房场景孪生」，缺「机器人本体 3D 模型 + 关节/姿态实时映射」 | 中 |
| 真机实时视频流 | 目前 simulated，缺真机摄像头流接入（RTSP/WebRTC） | 中 |
| 人形机器人 | 占位只读，未接入控制 | 低 |
| 校园/园区多区域拓扑 | 参考项目面向校园，智维Agent 面向数据中心厂房，场景不同 | — |

---

## 四、结论

- **当初定案「只蒸馏统一多设备接入」——已完成**，且在此基础上智维Agent 自身已具备 3D 场景孪生、视觉预警、平台助手、日志诊断能力，与参考项目**能力面基本对齐**。
- **本质差异在场景**：参考项目是「校园多设备巡检」，智维Agent 是「数据中心智能运维」——设备接入、视觉、孪生、助手是通用能力，场景与设备本体孪生是差异化部分。
