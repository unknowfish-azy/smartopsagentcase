# 云计算与云原生功能补充

来源：用户提供的《云计算运维 + 云原生运维 知识与工具全景》。不改写已有知识正文。

## 本轮落地

左侧云原生工程菜单新增 6 个入口，复用 Tools 工作台与远程运行接口：

| 工具 ID | 功能 | 执行依赖 |
| --- | --- | --- |
| docker-compose-status | Compose 项目清单 | Docker Compose 插件 |
| helm-releases | 指定命名空间发布清单，最多 100 条 | Helm 和已授权 Context |
| k8s-storage | PVC 与 StorageClass | kubectl 及对应权限 |
| k8s-rbac-check | 当前身份读取 Pod 和日志的权限 | kubectl |
| mesh-status | 网格命名空间 Pod、Service | kubectl，实际部署命名空间 |
| terraform-environment | Terraform 版本环境 | Terraform CLI |

新增工具都使用服务端固定命令、命名空间校验、用户所属运行连接、30 秒命令超时、退出码、TraceId 与既有运行记录。非零退出码会终止后续步骤。没有远程连接时不执行；没有工具安装时返回真实错误。

工作台新增 12 领域能力覆盖区，显示知识、工具、优先级、实现进度与下一步。不把实现进度当成环境健康结果。

## 尚未完成的连接能力

1. 公有云 OpenAPI：需云厂商适配器、凭据引用、地域、分页、速率限制和最小权限，先实现资源只读清单。
2. 数据库与观测数据源：现有模板中的 smartops 子命令不能视为已经安装的适配器；需真实连接、查询上限、时间范围及脱敏。
3. GitOps / CI：先接发布历史、状态和差异；发布、回滚绑定目标版本与审批。
4. 自动化：Ansible / SaltStack / Fabric 需任务模板、目标白名单和并发上限。
5. 安全：先接 Trivy / kube-bench / Falco 报告或事件，再增加限定范围的执行任务。
6. 服务网格：当前只看组件清单；拓扑、流量规则、分布式追踪需专用 API。

未对真实云账号、集群、Docker 或 Terraform 环境执行命令。单元测试使用受控运行替身，不代表实际环境健康。

## 接口和数据库

不变更数据库结构。复用 GET /api/operations/tools、POST /api/operations/tools/preview 和既有 runtime 工具执行接口。新增工具定义会出现在工具清单中。

## 验收

前端：所有入口可打开，中文说明与命令预览可见，非法命名空间拒绝，离线不执行。
后端：固定命令可预览，参数注入被拒绝，跨用户运行被拒绝，执行证据进入既有记录链。
部署：后端重启后工具清单包含新增 ID；真实远程验证需使用已授权的目标连接。
