# 演示服务器与主题同步验收

## 使用入口

- 服务器列表点击“演示案例（6 台）”，或打开 `/servers?view=demo`。
- 包含 Web、MySQL、Redis、Kubernetes、Harbor、离线实验节点，覆盖在线、告警、离线状态。
- 演示详情提供固定配置与模拟 CPU / 内存 / 磁盘数据；离线数据标注未采集，不伪装为零占用。
- 默认仍为真实服务器列表。演示数据不进入真实 store、数据库或真实统计，不提供 SSH、编辑、删除操作，也不会作为真实 API 故障时的回退数据。

## 主题修正

- 浅色使用深色正文、辅助文字与特效；深色使用浅色正文与发光特效。深色填充按钮保留有对比度的前景色，不做整页反色。
- Element Plus 表格、表单、弹窗与状态标签使用语义色。卡片、表格单元格、按钮不再因背景过渡滞后出现瞬时白底白字。
- 首页 Three.js 与 Canvas 特效响应主题切换，不因换色重建场景；Three.js 仍仅在增强首页异步加载。
- 知识库的 scoped `:global` 选择器原来编译为直接修改文档根节点，将整页透明度降为 0.2；现在限定到特效元素，并有编译产物和浏览器回归检查。
- 知识库输入框改用主题表面色；平衡视觉下 WebGL 背景使用主题墨色，轻量/减少动态模式不挂载该背景。
- Agent 原生刷新按钮原来固定白底，在深色 color-scheme 下出现白字白底。现在按钮、任务卡及流程块使用主题色，刷新过程中明确显示“刷新中…”并禁用重复点击，失败后恢复操作。
- 侧栏与顶栏玻璃装饰层原来 `top:35%`、高度接近整栏；浅色关闭模糊后暴露错位黑框。现在装饰层贴合容器实际边界，只保留内高光，不叠加黑色内框。手机菜单使用可用全宽与主题底色，补齐健康诊断图标。

## 验证证据

工作目录为 `frontend`：

```powershell
npm.cmd test
npm.cmd run build
$env:SMARTOPS_BROWSER_BASE_URL='http://127.0.0.1:4175'
node test/server-demo-theme.browser.mjs
node test/agent-refresh.browser.mjs
node test/sidebar-theme.browser.mjs
node test/workbench-foundation.browser.mjs
node test/visual-mode.browser.mjs
```

- 前端单测：303 通过，0 失败；生产构建通过。
- 演示/主题浏览器检查：375/1440px、深浅主题、平衡/轻量视觉；模拟数据隔离、真实列表故障不回退演示、详情只读、抽样文字对比度、首页实时换色与减少动态检查通过。
- 代表页面抽查：知识库、Harbor、云原生、智能体、模型中心；知识库另验证平衡模式背景实时换色。
- 刷新按钮：375/1440px，深浅色、悬停、聚焦、加载中、成功与失败恢复通过。修复前捕获的文字/背景对比度为 1:1。
- 菜单边框：375/900/1440px，深浅主题，展开、收起、移动菜单尺寸和无横向溢出通过。
- 工作台基础与视觉模式回归通过。浏览器使用 Mock API，不代表真实 Harbor、SSH、模型服务或数据库集成已验证；本次没有修改后端或数据库。
- `test-artifacts` 下保存测试日志；`frontend/test-artifacts` 下保存截图。没有将抽样检查描述为全系统无障碍认证。
- 保留 `vendor-three` 约 519.73 kB 构建警告，未提高警告阈值；资源仍异步隔离。
