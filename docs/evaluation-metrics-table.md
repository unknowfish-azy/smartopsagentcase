## 二、三模块推荐搭配

| 模块 | 必报指标 | 加分指标 |
|---|---|---|
| AnomalyTransformer 时序 | PR-AUC、事件级 F1、TTD、NAB Score | FPR、Delay、Coverage |
| GNN 根因定位 | A@1、A@3、MRR | MAP、NDCG |
| TinyBERT / TextCNN 日志 | F1、PR-AUC、ARI | AMI、Silhouette、Recall@k |
| **安全基线 / Agent 执行链** | **红线拦截率、红线误杀率、审计落盘覆盖率、fail-closed 启动验证率** | **哈希链验证率、L1 注入拦截率、L3 仲裁准确率** |

## 三、避坑（三条红线 + 安全基线红线）

1. 异常检测不放 Accuracy（不均衡虚高）；
2. GNN 不用 F1（排序任务，用 A@k / MRR）；
3. 区分「点级 vs 事件级」F1，优先报事件级；
4. **安全基线 FN 必须为 0**——红线漏拦 = 破坏性操作被执行，不存在"权衡取舍"；
5. **fail-closed 启动验证率必须 100%**——任何篡改都不能让装配继续；
6. **审计落盘覆盖率必须 100%**——拦截决策不落盘 = 事后不可追溯。
