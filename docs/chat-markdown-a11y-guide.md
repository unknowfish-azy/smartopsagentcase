# 对话板 Markdown 渲染与无障碍说明

> 适用范围：AI 对话面板中助手消息的 Markdown 渲染（完成后态）。
> 关联文件：[markdown.js](../frontend/src/components/ai/markdown.js)、[AiChatPanel.vue](../frontend/src/components/ai/AiChatPanel.vue)。

## 1. 渲染分流与语义

| 消息状态 | 呈现 | 无障碍语义 |
| --- | --- | --- |
| 助手 · 已完成 | Markdown 块级渲染 | 真实 `h1-h4 / ul / ol / blockquote / pre / code / a` 元素 |
| 助手 · 流式中 | 纯文本逐字 + 光标 | 纯文本，随 `role="log"` 实时播报 |
| 用户 / 错误消息 | 纯文本 | 纯文本，错误另有 `role="alert"` 提示 |

Markdown 转换产出的是**语义化 HTML**而非装饰性标记：屏幕阅读器用户可以按标题/列表导航（NVDA 的 `H`/`L` 快捷键、VoiceOver 转子），代码块以块级代码语境播报，而不是读出 `**`、`#`、`` ` `` 等原文字符。

## 2. 安全即无障碍

- **先转义再转换**：全部输入先做 HTML 转义，`<script>`、`<img onerror>` 等注入只会以转义文本显示，无法伪装成界面元素——屏幕阅读器不会把攻击载荷误读为页面结构。
- **链接白名单**：仅 `http/https` 生成 `<a>`，并强制 `target="_blank" rel="noopener noreferrer"`；`javascript:` 等协议保留为不可点击的纯文本，不产生可聚焦的虚假控件（虚假控件会污染 Tab 序，损害键盘用户的方向感）。
- **零依赖**：渲染器不引第三方库，无供应链风险，行为由 5 项单元测试锁定（[chat-markdown.test.mjs](../frontend/test/chat-markdown.test.mjs)）。

## 3. 动效与降级

- 完成态消息容器复用 `ml-stream-lines`：子块级元素错峰淡入（90ms 步进），与逐行揭示旧方案同一套动效门禁；
- 「减少动效」/「轻量视觉」档与 `prefers-reduced-motion` 下淡入自动关闭（由 [motion-layer.css](../frontend/src/assets/styles/motion-layer.css) 的视觉档规则统一处理）；
- 动效只影响透明度/位移，不改变内容出现时机——内容在动画开始前已存在于 DOM，屏幕阅读器不依赖动画完成。

## 4. 已知边界（如实声明）

| 边界 | 说明 |
| --- | --- |
| 消息内标题从 `h1` 起 | 回复内容由模型生成，标题层级不保证衔接页面大纲；SR 用户按标题导航时会把消息内标题当作独立小节，属预期行为 |
| 代码块横向滚动不可键盘聚焦 | `pre` 未加 `tabindex`，键盘用户无法滚动超宽代码行；当前代码块宽度受消息气泡约束，超宽场景少见，暂不引入可聚焦容器 |
| 不支持表格/图片/删除线等扩展语法 | 这些语法按普通段落文本显示，不丢失内容、只不排版 |
| 完成态替换会触发一次 live region 更新 | `role="log"` 区域内流式文本 → Markdown 块的替换可能让 SR 重复播报一次收尾内容；为控制播报长度未做 aria-busy 抑制，属已接受的折中 |

## 5. 验证清单

- [ ] 发送一条会触发列表/代码块回答的问题：NVDA/VoiceOver 中按标题与列表导航可定位各块
- [ ] 回复中含 `**加粗**` 字面量时：视觉上显示为加粗，SR 不读出星号
- [ ] 回复中含 `javascript:` 伪协议链接时：不产生可 Tab 聚焦的链接
- [ ] VISUAL 切到「减少动效」：完成态消息直接呈现，无淡入
- [ ] 流式输出期间：文本实时可见且光标动画在 reduced-motion 下关闭
- [ ] 外部链接新标签页打开，原页面焦点不丢失

## 6. 不做的事

- 不在消息内注入可交互控件（按钮/复选框）——渲染器输出限定为排版标签；
- 不为 Markdown 容器单独申请焦点——消息区已有 `tabindex="-1"`，Esc 可从输入框回到消息区；
- 不用 CSS `content` 添加朗读文本——所有语义都来自真实 DOM。
