快速开始 —— 四个双击入口
========================================================

1-检查环境.bat
    体检：Node / Python / JDK17 / MySQL / Redis 是否齐全，端口有没有被占。
    缺什么会直接给 winget 安装命令。

2-安装环境.bat      （只需跑一次，需要联网）
    装 Python 依赖、生成 .env（含随机密钥）、建 smartops 库、
    检查前端依赖与后端 jar。结束时打印管理员账号密码。

3-启动平台.bat
    依次拉起 Redis → 后端(8080) → 知识服务(8002) → AI 服务(8001)
    → 用户端(5173) → 管理端(5174)，每个服务都要过健康检查才算成功。
    关掉窗口不影响，服务在后台跑。

4-停止平台.bat
    按进程号回收全部应用服务，再按端口兜底核对。

--------------------------------------------------------
常用参数（在 bat 后加，或在本目录开 PowerShell 调用 ps1）
--------------------------------------------------------
  2-安装环境.bat -Lite                    不装 torch/sentence-transformers，知识库降级为 hash 向量
  2-安装环境.bat -MysqlRootPassword 口令   root 口令不是默认值时指定
  2-安装环境.bat -AdminPassword 自定义密码 指定管理员初始密码
  2-安装环境.bat -ReinstallNpm            强制重装前端依赖
  2-安装环境.bat -SkipDb                  跳过建库
  3-启动平台.bat -Open                    启动完成后自动打开浏览器
  3-启动平台.bat -SkipAdmin               不起管理端（省内存）
  4-停止平台.bat -All                     连 Redis 一起停

--------------------------------------------------------
脚本在哪
--------------------------------------------------------
  scripts\_common.ps1    公共函数（路径推导、健康检查、启停、密钥生成）
  scripts\check-env.ps1  体检
  scripts\setup.ps1      安装
  scripts\start.ps1      启动
  scripts\stop.ps1       停止

所有路径都按脚本自身位置推导，整个目录可以放在任意盘、任意目录，
不需要改脚本里的任何路径。
