# 智维 Mini 使用指南

## 当前能力

智维 Mini 是 SmartOpsAgent 的本地只读问答助手。核心引擎使用本机 Ollama 和已安装的本地模型，默认模型为 qwen3:1.7b。可以解释运维概念、结合项目知识给出排查建议，并分析你在当前对话中主动提供的日志或问题描述。回答由模型实际生成，不使用预设成功回复。

本指南描述核心引擎能力，不代表当前环境已经完成模型安装、API 部署或界面验收。运行状态显示模型已安装，仅说明运行时在线且标签存在，不等于每次推理都成功或答案一定正确。

## 知识与参考来源

引擎只检索项目知识根目录中的 linux 下的 Markdown 文件、cloud_ops 和 assistant 的直接 Markdown 文件，以及 smartopsagent_brain.md。中文按轻量词项匹配，英文匹配不区分大小写；不使用外部搜索或云端向量服务。

每次最多选取 3 段参考资料。来源由服务端检索结果生成，不采信模型自行编造的路径。引用表示回答时提供了该资料，不保证回答中的每句话都已被资料证实；请结合原文核对。

知识文本是引用数据，不是要求助手执行的指令。检索不会扫描 .env、运行时目录、用户上传、其他账号数据或白名单之外的文件，也不跟随符号链接或目录联接。找不到相关资料时仍可进行一般问答，但不得把无来源回答当作已核实的项目事实。

索引采用首次检索时的只读快照。更新知识文件后，需要重启后端来刷新索引。每个文件最多 64 KiB；最多索引 128 个文件、累计 2 MiB、512 个片段；每个文件最多 16 个片段，每段最多 1000 字符。目录遍历和深度也有限制，超限或无法安全读取的内容会被跳过，因此检索不是完整知识库扫描。

## 问题与历史

当前问题最多 2000 字符。引擎仅接受 user 和 assistant 文本历史，保留最近最多 12 条；每条截取最多 4000 字符，再按照整体提示预算优先保留较新的内容。历史、参考资料、系统提示和当前问题合计最多 7000 字符，历史预算不超过 6000 字符。

模型上下文参数为 8192，最大输出 512 token，关闭思考输出和流式输出。字符预算不是精确 token 计数，较长问题和历史可能被裁剪或影响回答完整性。追问时建议重述关键环境、报错和时间范围。

## 明确不具备的能力

Mini 不执行 Shell、SSH、SQL 或任何工具，不修改配置、知识文件或业务数据；不会自动连接服务器、实时监控、截屏、修复故障或替你确认操作成功。给出命令建议不代表该命令已经运行。

Mini 不读取其他会话历史或账号凭据，不自动切换到外部模型，不调用云端模型服务。知识文件中的产品规划不代表这些功能已经在 Mini 中接入。

## 不可用与重试

状态探测最多等待 2 秒，并短暂缓存 3 秒。模型未安装时显示 model_missing；运行时离线或未及时响应时显示 offline。生成请求最多等待 120 秒；单个引擎实例同时只处理一个生成请求。

- 503：运行时不可用、本地模型缺失、连接失败或生成超时。检查本地运行时和模型后再重试。
- 502：本地生成失败，或返回了无效、不完整、空白或超限的响应。不会用模拟答案代替失败。
- 429：已有问题正在生成，请等待后再重试。

诊断建议需要人工判断。对重启、删除、变更或其他有风险的操作，应先确认影响范围、备份、审批和回滚方法；不要仅凭模型回答直接操作生产环境。
